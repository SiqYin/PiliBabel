> **અસ્વીકરણ.** PiliBabel એ **બિનસત્તાવારી, ઓપન-સોર્સ, થર્ડ-પાર્ટી** ક્લાયન્ટ છે. તે bilibili / bilibili Inc. સાથે **સંલગ્ન, મંજૂર અથવા પ્રાયોજિત નથી**. દરેક API અધિકૃત જાહેર એન્ડપોઇન્ટ્સ પરથી એકત્રિત કરવામાં આવી છે; **કોઈ પણ પેઇડ સામગ્રી અનલોક કે ક્રેક કરવામાં આવતી નથી**. સંપૂર્ણ [અસ્વીકરણ](#અસ્વીકરણ) અને [લાયસન્સ](#લાયસન્સ) વિભાગો વાંચો.

## PiliBabel શું છે?

PiliBabel એ **[PiliNara](https://github.com/Starfallan/PiliNara) ની ઉપર બનાવેલો સ્વતંત્ર થર્ડ-પાર્ટી ફોર્ક છે**, અને PiliNara જે બધું વારસામાં મેળવે છે તે બધું તે પણ વારસામાં મેળવે છે:

```
bilibili (અધિકૃત જાહેર API)
        ▲
   PiliPala / PiliPalaX        — મૂળ પ્રોજેક્ટ
        ▲
   PiliPlus                    — સક્રિય ફોર્ક
        ▲
   PiliNara                    — PiliPlus નો ફોર્ક (વ્યક્તિગત ફેરફારો)
        ▲
   PiliBabel  ← તમે અહીં છો   — PiliNara નો ફોર્ક
```

PiliBabel **PiliNara / PiliPlus ની દરેક સુવિધાને જાળવી રાખે છે** (નીચે નજીકમાં આવેલી [વારસામાં મળેલી લક્ષણ યાદી](#વારસામાં-મળેલી-લક્ષણ-યાદી-pilinara--piliplus-માંથી) જુઓ) અને **એવી બે મુખ્ય ક્ષમતાઓ ઉમેરે છે જે અપસ્ટ્રીમ ક્લાયન્ટ્સ પાસે નથી**:

> **AI ઇન્ટરફેસ અને સામગ્રી અનુવાદ** — આખી એપ (UI લેબલ્સ, વિડિયો શીર્ષકો, UP નામો, ટિપ્પણીઓ, ડાયનેમિક્સ, ફીડ, અને લાઇવ ડાનમાકુ (danmaku) સુદ્ધાં) **તમારી** પસંદ કરેલી ભાષામાં રેન્ડર થાય છે.

અને 1.0 થી આ બધું **ઇન્સ્ટોલ કરતાં જ કામ કરે છે**: અનુવાદ મોડેલ **બિલ્ટ-ઇન છે**. bilibili એ પોતાનું અનુવાદ મોડેલ કુટુંબ [Index-Translate](https://github.com/bilibili/Index-Translate) ઓપન-સોર્સ કર્યું છે અને તેને મફત જાહેર એન્ડપોઇન્ટ પરથી પૂરું પાડે છે. PiliBabel તેને લક્ષ્ય બનાવીને જ શિપ થાય છે, એટલે એપ ઇન્સ્ટોલ કરતાં જ અનુવાદ કામ કરવા લાગે છે — કોઈ સાઇન-અપ નહીં, કોઈ કી નહીં, કોઈ બિલ નહીં. જો તમે તમારો પોતાનો મોડેલ વાપરવા માંગતા હો, તો પોતાના-API વાળો રસ્તો હજુ પણ ત્યાં જ છે, એક ટેપના અંતરે.

> **હેડફોન ઓડિયો જે સાચમસાચ સિંકમાં રહે છે** — બ્લૂટુથ કે વાયર્ડ હેડફોન્સ સાથે, અવાજ હવે ચિત્રથી પાછળ રહેતો નથી. અધિકૃત એપ આ સાચું કરે છે; PiliNara અને PiliPlus ડિફૉલ્ટ રૂપે નથી કરતા. PiliBabel હવે mpv પાસેથી પહેલા **AudioTrack** માંગે છે, જે અધિકૃત ક્લાયન્ટની જેમ ઓડિયો આઉટપુટ લેટન્સીને *માપે છે*, **OpenSL ES** ની જેમ નહીં જે તેનો માત્ર *અંદાજ* લગાવે છે.

## મુખ્ય લક્ષણો

- **સિંકમાં રહેતું હેડફોન ઓડિયો.** પ્લેયર હવે ડિફૉલ્ટ રૂપે mpv નું **AudioTrack** બેકએન્ડ (`audiotrack,aaudio,opensles` ક્રમ) વાપરે છે, **OpenSL ES** ની જગ્યાએ. AudioTrack *માપેલી* આઉટપુટ લેટન્સી જણાવે છે — તે પ્લે થયેલા ફ્રેમની ગણતરી અને ઉપકરણના પ્રેઝન્ટેશન ટાઇમસ્ટેમ્પ વાંચે છે — બરાબર એ જ રીતે જેમ અધિકૃત bilibili એપ અને Android નું પોતાનું `MediaSync` ચિત્ર અને અવાજને સાથે રાખે છે. OpenSL ES માત્ર *અંદાજ* લગાવે છે, એટલે બ્લૂટુથ હેડફોન્સ પર ઓડિયો ઘડિયાળ ડ્રિફ્ટ થતી હતી અને ચિત્ર વહેલું બતાવાતું હતું. ટેસ્ટિંગમાં, આ લેગ લગભગ સંપૂર્ણપણે ગયો છે. સેટિંગ્સ → વિડિયો → ઓડિયો આઉટપુટ ઉપકરણમાં તેને ગમે ત્યારે ફરી ગોઠવી શકાય.

- **AI અનુવાદ, દરેક જગ્યાએ.** નેવિગેશન ટૅબ્સ, વિડિયો કાર્ડ્સ, વિગત પેજો, ટિપ્પણીઓ, ડાયનેમિક્સ, અને મારું / મનગમતું / ઇતિહાસ / સંદેશા / શોધ સરફેસ — એક વૈશ્વિક સ્વીપ **~1,650+ UI સ્ટ્રિંગ્સ** ને આવરી લે છે, સાથે ડાયનેમિક સામગ્રી (શીર્ષકો, લેખક નામો, ક્રિયા ગણતરીઓ).
- **બે એન્જિન, એક સ્વિચ.** *બિલ્ટ-ઇન* (ડિફૉલ્ટ) bilibili ના અધિકૃત **Index-Translate-35B-A3B** મફત એન્ડપોઇન્ટનો ઉપયોગ કરે છે — ગોઠવવાનું કંઈ નથી. *પોતાનું API* અગાઉનું વર્તન જાળવે છે: તમારા પોતાના બેઝ URL / કી / મોડેલ સાથે કોઈપણ OpenAI-સુસંગત `/chat/completions` એન્ડપોઇન્ટ તરફ તેને નિર્દેશિત કરો. AI વિડિયો-સારાંશ સુવિધા અને AI અનુવાદ સુવિધા પાસે હજુ પણ **સંપૂર્ણપણે સ્વતંત્ર** એન્ડપોઇન્ટ્સ અને સેટિંગ્સ છે, બંને એક જ **"AI લક્ષણો"** પેજ હેઠળ રહે છે.
- **એક જ ભાષા યાદી, બંને એન્જિન માટે.** લક્ષ્ય-ભાષાની યાદી એન્જિન પ્રમાણે વહેંચાયેલી નથી — તમે જે પણ એન્જિન પસંદ કરો તે જ યાદી આપવામાં આવે છે. તે bilibili ના અધિકૃત મોડેલની **151 ભાષાઓ** ને એવી **6 વધુ ભાષાઓ** સાથે એકત્રિત કરે છે જેને તે આવરતી નથી — પરંપરાગત ચાઇનીઝ, સરળ અને પરંપરાગત વુ, મેનલેન્ડ અને તાઇવાન હોક્કિયન, ઝુઆંગ. પ્રાદેશિક અને લિપિ પ્રકારોને ભેગા નહીં કરી **અલગ એન્ટ્રીઓ** તરીકે રાખવામાં આવે છે — મોરોક્કન / ઇજિપ્તિયન / નજદી / લેવન્ટાઇન અરબી દરેક પોતાની અલગ પસંદગી છે, એ જ રીતે સિરિલિક-વર્સેસ-લેટિન સર્બિયન, ઉઝ્બેક અને ઉર્દૂ.
- **કવરેજ વિશે પ્રામાણિક.** અધિકૃત યાદીની અંદરની ભાષાઓ bilibili ના મોડેલ દ્વારા આવરાયેલી છે. બહારની થોડી — પરંપરાગત ચાઇનીઝ, સરળ અને પરંપરાગત વુ, મેનલેન્ડ અને તાઇવાન હોક્કિયન અને ઝુઆંગ — હજુ પણ યાદીમાં દેખાય છે, આ મુજબ ચિહ્નિત પણ છે, જેથી તમને એક નજરમાં ખબર પડે કે વધુ સારા પરિણામ માટે કદાચ તમારા પોતાના મોડેલની જરૂર પડી શકે.
- **એક વાર અનુવાદ કરો, પછી એ સ્થિર.** દરેક સોર્સ સ્ટ્રિંગનો અનુવાદ **બરાબર એક જ વાર** થાય છે; પરિણામ સ્થાનિક રીતે સાચવાય છે અને તમે સ્ક્રીન ફરી ખોલો ત્યારે **ક્યારેય ફરી અનુવાદ થતો નથી** — સ્થિર, અણધારી શકાય તેવા અનુવાદો માટે અધિકૃત ક્લાયન્ટ જેવો જ સિદ્ધાંત.
- **દરેક ટિપ્પણી માટે મૂળ ⇄ અનુવાદ ટૉગલ** (ચાઇનીઝ શબ્દ નહીં, એક નાનું આઇકન). `@mentions / [emoji] / #topics# / links` ને ટોકન્સ તરીકે સાચવવામાં આવે છે, અને **હાઇપરલિંક્સ ધરાવતી ટિપ્પણીઓ પણ લિંકને ક્લિક-કરી શકાય તેવી રાખીને અનુવાદ થાય છે**.
- **ડાનમાકુ (danmaku) અનુવાદ** — પ્લેયરની ઉપર-જમણી કંટ્રોલ હરોળમાં સ્વતંત્ર ટૉગલ, **ડિફૉલ્ટ રૂપે બંધ**, અને એક પુષ્ટિકરણની પાછળ જેનો પોતાનો ટેક્સ્ટ પણ અનુવાદિત થાય છે. ચાલુ કરવા પર, પ્લેહેડ કરતાં આગળના ડાનમાકુ **~15-સેકંડના બેચ** માં પહેલેથી અનુવાદિત થઈ જાય છે (વચ્ચે સીક કરવાનું શરૂઆતથી નહીં પણ બરાબર રીતે સંભાળાય છે), જેથી તે સ્ક્રીન પર સરકીને આવે ત્યાર સુધીમાં અનુવાદ સામાન્ય રીતે તૈયાર હોય છે.
- **થિંકિંગ-મોડ સ્વિચ** (`enable_thinking`) ગુણવત્તા-વર્સેસ-ઝડપ માટે, સાથે સેટિંગ્સમાં **"ટેસ્ટ અનુવાદ"** અને **કૅશ-સાફ** બટનો.
- **ઝડપી ભાષા બદલી**: સ્થાયી કૅશ પર મર્યાદિત સમાંતરતા સાથે બેચવાળી વિનંતીઓ; ભાષા બદલવાથી વર્તમાન સ્ક્રીન એક વાર દબાણથી ફરી બને છે, જેથી તમે અણ-અનુવાદિત ટેક્સ્ટ સામે જોતા રહી ન જાઓ. AI અનુવાદ બંધ કરવાથી આખું UI મૂળ ટેક્સ્ટ પર પાછું ફરે છે અને એકેય વિનંતી જારી થતી નથી.
- **પહેલી-લૉન્ચ ઑનબોર્ડિંગ.** એપ પહેલી વાર ખોલતાં, એક અંગ્રેજી ડાયલોગ અનુવાદ ચાલુ કરવાની ઓફર કરે છે. સ્વીકારવાથી અનુવાદ સક્રિય થાય છે, બિલ્ટ-ઇન મોડેલ પસંદ થાય છે, AI સેટિંગ્સ પેજ ખૂલે છે અને તરત પૂછાય છે કે તમને કઈ ભાષા જોઈએ છે — એટલે નવો વપરાશકર્તા ઇન્સ્ટોલથી અનુવાદિત એપ સુધી બે ટેપમાં પહોંચી જાય છે.
- **વિશ્વભરમાં કામ કરતું પ્લેબેક.** PiliBabel તમને મેનલેન્ડ (Aliyun/Shenzhen) નોડ પર પિન કરવાને બદલે, bilibili નું જિયો-રૂટેડ `playurl` પહેલેથી ઑફર કરતું ઓવરસીઝ એજ (ગ્લોબલ **Akamai**, `mirror*ov`, `cn-hk-eq-bcache`) પસંદ કરે છે — જેથી મેનલેન્ડ ચીનની બહારના વપરાશકર્તાઓ હવે અટકતા નથી ("ઓડિયો ચાલુ રહે છે, વિડિયો સ્થિર થઈ જાય છે"). તમે હજુ પણ સેટિંગ્સમાં CDN ને જાતે પિન કરી શકો છો.
- **"થીમ અને રંગ" પેજ, Material You શૈલીમાં.** લાઇટ / ડાર્ક / સિસ્ટમને-અનુસરો **ત્રણ લાઇવ પ્રીવ્યૂ કાર્ડ્સ** માંથી પસંદ થાય છે — દરેક એ મોડ જે રંગો લાગુ કરશે તે જ ચોક્કસ રંગોમાં વાસ્તવિક ઇન્ટરફેસનું એક નાનું રૂપ રેન્ડર કરે છે ("સિસ્ટમને અનુસરો" કાર્ડ કર્ણસમ રીતે વહેંચાયેલું છે, ડાર્ક ઉપર લાઇટ). તેમની નીચે: **ડાયનેમિક રંગ** (જ્યાં ઉપકરણ આધાર આપે ત્યાં સિસ્ટમ વૉલપેપરમાંથી લેવાય છે), **હાઇ-કૉન્ટ્રાસ્ટ ડાર્ક** (સાચા-કાળા સરફેસ, રાત્રે આંખો માટે સરળ) અને **હંમેશા-ડાર્ક પ્લેયર**. રંગનો અડધો ભાગ સંપૂર્ણ FlexScheme પૅલેટ જાળવે છે — **19 સીડ રંગો** સાથે એક અલગ **"પૅલેટ શૈલી"** જે નક્કી કરે છે કે દરેક કન્ટેનર રંગ સીડમાંથી કેવી રીતે બને, તમારી પસંદગીના સીડથી સ્વતંત્રપણે.
- **LXGW WenKai એપ સાથે આવે છે.** **LXGW WenKai (霞鹜文楷)** ટાઇપફેસ **બંડલ કરેલું અને ડિફૉલ્ટ તરીકે સેટ કરેલું છે** — ઇન્સ્ટોલ કરતાં જ તમારી પાસે હોય તેવું એક ગરમ, ખૂબ વાંચવા-લાયક ચાઇનીઝ ફોન્ટ, પિકરમાં એક શોધવાની જરૂર વિના. તે આખા ઇન્ટરફેસ પર *અને* ડાનમાકુ પર લાગુ થાય છે. તમે હજુ પણ સિસ્ટમ ફોન્ટ પર પાછા ફરી શકો, ઇન્સ્ટોલ થયેલું કોઈપણ સિસ્ટમ ફોન્ટ પસંદ કરી શકો, અથવા તમારું પોતાનું `.ttf` / `.otf` / `.ttc` ઇમ્પોર્ટ કરી શકો; જે ફોન્ટ તમે પહેલાં સ્પષ્ટપણે પસંદ કર્યું હતું તે અપગ્રેડમાં પણ ટકી રહે છે. વજન અને કદ આગલી જેમ જ ગોઠવી શકાય છે.

## ઑફલાઇન ઓડિયો કૅશિંગ અને લોકલ ફોલ્ડરમાં ડાઉનલોડ (PiliBabel માટે અનન્ય)

અપસ્ટ્રીમ PiliNara / PiliPlus પાસે ન હોય તેવી બે ક્ષમતાઓ — બંને તમારા મીડિયાને ઑફલાઇન સાચા અર્થમાં તમારું બનાવવા માટે.

### ઓડિયો કૅશ કરો (ફક્ત ઓડિયો ઑફલાઇન કૅશ)

- **વિડિયો નહીં, ટ્રેક.** વિડિયો પેજના મેનૂમાં *વિડિયો કૅશ કરો* ની ઠીક નીચે *ઓડિયો કૅશ કરો* એન્ટ્રી હોય છે, સાથે સાંભળવાનું-વિડિયો પેજની ઉપરની પટ્ટીમાં એક અલગ ઓડિયો-કૅશ બટન.
- **ગુણવત્તા સ્તર પસંદ કરો.** Hi-Res લૉસલેસ, Dolby Atmos, 192K, 132K અથવા 64K — એ જ પ્રીસેટ યાદી જે વિડિયો ગુણવત્તા પિકર વાપરે છે.
- **મૂળ કન્ટેનર, ટ્રાન્સકોડિંગ નહીં.** ફાઇલ CDN જે રીતે આપે છે એ જ રીતે લખાય છે: `m4a`, `mp3`, `flac`, `wav`, `aac` અથવા `ogg`.
- **પોતાનો મોડ્યુલ.** કૅશ પેજ *કૅશ થયેલા વિડિયો* / *કૅશ થયેલા ઓડિયો* માં વહેંચાયેલું છે અને યાદ રાખે છે કે તમે છેલ્લે કયા મોડ્યુલ પર હતા.
- કૅશ થયેલી ઓડિયો આઇટમ પર ટેપ કરવાથી ઓડિયો પ્લેયર તરત ખૂલે છે; આઇટમ્સ એક-એક કરીને અથવા થોકમાં ડિલીટ થઈ શકે છે.

### લોકલ ફોલ્ડરમાં ડાઉનલોડ કરો

- **પોતાની અલગ મેનૂ એન્ટ્રી.** *લોકલ ફોલ્ડરમાં ડાઉનલોડ કરો* એ વિડિયો પેજના મેનૂમાં *ઓડિયો કૅશ કરો* ની ઠીક નીચે એક અલગ એન્ટ્રી છે — એપની અંદર કૅશ કરવું અને ફોલ્ડરમાં સાચવવું એ બે અલગ ક્રિયાઓ છે.
- **વિડિયો ડાઉનલોડ કરો કે ઓડિયો ડાઉનલોડ કરો.** આ એન્ટ્રી પહેલા પૂછે છે કે કઈ જોઈએ છે, પછી ગુણવત્તા સ્તર પૂછે છે (વિડિયો ગુણવત્તા / ઓડિયો ગુણવત્તા પિકર).
- **તમારું ફોલ્ડર, તમારા નિયમો.** સિસ્ટમ ફાઇલ મેનેજર દ્વારા ગમે તે ફોલ્ડર પસંદ કરો (સેટિંગ્સ → *લોકલ ફોલ્ડરમાં ડાઉનલોડ કરો*), અને ગમે ત્યારે બદલો કે સાફ કરો. જો તમે હજુ કંઈ પસંદ કર્યું ન હોય, તો ફોલ્ડર પિકર તરત ખૂલી જાય છે.
- **સીધા ચલાવી શકાય તેવી ફાઇલો.** વિડિયો એક જ મક્સડ સ્ટ્રીમ તરીકે (`fnval=1`) મેળવાય છે, એટલે ડિસ્ક પર ઉતરતી વસ્તુ એક સાદી MP4 છે જે તમે કોઈપણ પ્લેયરને આપી શકો — જોડવા માટે કોઈ સાઇડકાર સ્ટ્રીમ્સ નથી.
- **ઓડિયો પોતાના મૂળ ફોર્મૅટમાં જ રહે છે** — ટ્રાન્સકોડિંગ નહીં, એપ-અંદરના કૅશની જેમ જ.
- ફાઇલોને વિડિયો શીર્ષક પરથી નામ અપાય છે અને પહેલેથી હાજર ડાઉનલોડ પર ક્યારેય ચઢાવી લેતી નથી.

**બિલ્ટ-ઇન એન્જિન માટે દરેક વિનંતીએ એક સ્ટ્રિંગ કેમ.** Index-Translate એક અનુવાદ *વિશેષજ્ઞ* છે, અને તેના લેખકો દ્વારા દસ્તાવેજિત કૉલિંગ પદ્ધતિ એક સિંગલ-આઇટમ ટેમ્પલેટ છે ("નીચેના ટેક્સ્ટનો X ભાષામાં અનુવાદ કરો, ફક્ત અનુવાદ જ આઉટપુટ કરો"). એટલે PiliBabel પોતાના-API સેટઅપ માટે વાપરતા નંબરવાળી-યાદી/JSON-એરે બેચ પ્રૉમ્પ્ટને બદલે, આ એન્જિન પર દરેક વિનંતીએ એક સ્ટ્રિંગ મોકલે છે. એન્ડપોઇન્ટ મફત છે, એટલે બેચ આઉટપુટ પર જુગાર રમીને મેળવવાનું કંઈ નથી — નિષ્ફળ જવાના રસ્તા ઘણા ઓછા રહે એ માટે થોડી વધુ વિનંતીઓ આપવી એ જાણીજોઈને કરેલો સોદો છે.

**0.3.x માંથી અપગ્રેડ કરી રહ્યા છો.** તમારી પોતાની API સેટિંગ્સ — બેઝ URL, કી અને મોડેલ — **તમે જેમ ગોઠવી હતી તેમ જ રહે છે**. એન્જિન પસંદગી માત્ર બિલ્ટ-ઇન મોડેલ પર ડિફૉલ્ટ થાય છે, એટલે અપગ્રેડ પછી પહેલી લૉન્ચ પર તમે bilibili ના મફત મોડેલ પર હશો; *સેટિંગ્સ → AI → AI લક્ષણો → અનુવાદ એન્જિન* ખોલીને *પોતાના API* પર પાછા ફરો, એટલે તરત જ તમારા અગાઉના સેટઅપ પર પરત આવી જાઓ.

## AI ઇન્ટરફેસ અનુવાદ કેવી રીતે કાર્ય કરે છે (ટેકનિકલ)

આ રિપોઝિટરીમાં **i18n / ARB રિસોર્સ લેયર નથી** — UI સ્ટ્રિંગ્સ હાર્ડ-કોડેડ ચાઇનીઝ છે. દરેક વિજેટને ફરી લખવાને બદલે, PiliBabel તેની ઉપર એક પાતળું અનુવાદ લેયર ઉમેરે છે:

1. **એક વૈશ્વિક લુકઅપ રૅપર.** `lib/services/ui_translate/` એક ટોપ-લેવલ `uiTx(String src)` આપે છે. જે વિજેટ ટેક્સ્ટ પહેલાં `Text('中文')` હતું તે `Text(uiTx('中文'))` બની જાય છે. એક સ્ક્રિપ્ટ કરેલા **કોડમોડ** (`tool/ui_translate_*.py`) એ આ બદલામણને આખા પ્રોજેક્ટ પર લાગુ કરે છે — આશરે **223 ફાઇલો / ~1,650+ સ્ટ્રિંગ્સ** — જ્યાં જરૂરી હોય ત્યાં હવે અમાન્ય `const` કીવર્ડ આપોઆપ દૂર કરતું (`const X<T>(...)` જેવા જેનેરિક્સ અને `const Positioned.fill(...)` જેવા ડૉટ-વાળા નામો સહિત, અને `static const` લિસ્ટ/મેપ ડિક્લેરેશન્સને `static final` માં ફેરવતું).
2. **એક `GetxService` કોર** (`ui_translate_service.dart`):
   - એક સ્થાયી **સોર્સ → અનુવાદ** કૅશ (GetStorage આધારિત), જેથી દરેક સ્ટ્રિંગનો અનુવાદ એક વાર થઈને હંમેશા માટે પુનઃઉપયોગમાં લેવાય;
   - `tx()` પહેલા એક `RxInt revision` વાંચે છે, પછી નક્કી કરે છે: બંધ હોય તો → મૂળ પરત આપે; લક્ષ્ય **સરળ ચાઇનીઝ (`zh-CN`)** હોય તો, API વિનંતી વિના મૂળ પરત આપે (Bilibili ની સોર્સ સામગ્રી મોટે ભાગે સરળ ચાઇનીઝ છે). બીજું દરેક લક્ષ્ય — પરંપરાગત ચાઇનીઝ, કૅન્ટોનીઝ, વુ/શાંઘાઇ, હોક્કિયન/મિન નાન સહિત — ગોઠવેલા એન્જિન મારફત જાય છે; ફક્ત ચાઇનીઝ-કુટુંબનું સભ્યપદ અનુવાદને છોડતું નથી. પછી કૅશમાંથી આપે અથવા **કતારમાં મૂકે**;
   - કતારમાં મૂકાયેલી સ્ટ્રિંગ્સ **દરેક-ચંક વધતા જતા લાગુ કરવા** સાથે એક **વર્કર પૂલ** દ્વારા ફ્લશ થાય છે (આવેલો દરેક ચંક `revision` વધારે છે જેથી ટેક્સ્ટ ધીમે ધીમે અપડેટ થાય), અને પરિણામો **સાચવાય** છે (થ્રોટલ્ડ). બેચ કદ અને સમાંતરતા એન્જિનને અનુસરે છે: બિલ્ટ-ઇન મોડેલ પર **દરેક વિનંતીએ 1**, તમારા પોતાના API પર **≤ 16, હવામાં ≤ 10**.
3. **એન્જિન રિઝોલ્યૂશન.** `TranslateProvider` (`builtin` / `custom`) નક્કી કરે છે કે ટ્રાન્સપોર્ટ કયો URL, કી અને મોડેલ વાપરે; નહીંં તો બંને એન્જિન એક જ કોડ પાથ અને એક જ ભાષા યાદી વહેંચે છે, એટલે એન્જિન બદલવું એક જ સેટિંગ છે, ક્યારેય અલગ ફીચર સેટ નહીં.
4. **ટ્રાન્સપોર્ટ** AI વિડિયો સારાંશની એ જ ચકાસાયેલી **સ્ટ્રીમિંગ** ચેનલનો ફરી ઉપયોગ કરે છે — `AiChatService.streamChat` → `stream: true` સાથે `{base}/chat/completions` (ફક્ત સ્ટ્રીમિંગ આધાર આપતા ગેટવે સાથે સુસંગત) — એ રીતે વિસ્તારેલું છે કે અનુવાદ પોતાના **જ** `apiUrl` / `apiKey` / `model` અને `enable_thinking` ફ્લેગ વાપરી શકે. આ ફેરફાર **બૅકવર્ડ-સુસંગત** છે, એટલે વિડિયો સારાંશ બિનબદલ કામ કરતું રહે છે.
5. **ઇન્ટરપોલેટેડ વાક્યો** `uiTxP(template, args)` વાપરે છે: `{0}`/`{1}` પ્લેસહોલ્ડર ધરાવતું આખું વાક્ય એક સ્થિર કી તરીકે અનુવાદિત થાય છે (પ્રૉમ્પ્ટ મોડેલને પ્લેસહોલ્ડર જાળવવા કહે છે), પછી મૂલ્યો પાછા મૂકાય છે — એટલે `"共 {0} 条"`-શૈલીની સ્ટ્રિંગ્સ ડાયનેમિક ભાગોને બગાડ્યા વિના અનુવાદિત થાય છે.
6. **ભાષા કોષ્ટક** (`app_language.dart`): દરેક `AppLanguage` એક ડિસપ્લે ઑટોનિમ, એક `toModel` પ્રૉમ્પ્ટ સ્ટ્રિંગ જે લિપિ/પ્રદેશ પ્રથાઓ એન્કોડ કરે છે, અને એ ફ્લેગ ધરાવે છે કે bilibili ની અધિકૃત યાદી તેને આવરે છે કે નહીં. લિપિ નિયમો (સરળ વર્સેસ પરંપરાગત, અને બોલી-સ્થિરતા સૂચનો) મોડેલ સુધી **ફક્ત પ્રૉમ્પ્ટ મારફત** પહોંચે છે, અને ક્લાયન્ટ પરનો એક નિશ્ચિત નૉર્મલાઇઝેશન પાસ પછી ખોટા ગ્લિફ સુધારે છે.
7. **ટિપ્પણીઓ** `uiTxComment(text, id)` મારફત જાય છે, `@ / [emoji] / #topic# / link` ને અકબંધ ટોકન્સ તરીકે રાખીને; લિંક્સ ધરાવતા રિચ-ટેક્સ્ટ સ્પાન્સ અનુવાદિત થાય છે જ્યારે લિંક ઓળખનાર સાચવાયેલું રહે છે, અને દરેક ટિપ્પણીનો id સેટ મૂળ ⇄ અનુવાદ ટૉગલ ચલાવે છે.
8. **ડાનમાકુ** (`danmaku/view.dart`): જ્યારે તેનો ટૉગલ ચાલુ હોય, એક પૉઝિશન લિસનર `[playhead, playhead + 15s]` ને એક-એક સેકંડ કરીને ચકાસે છે અને દરેક ડાનમાકુની સામગ્રી પર `uiTx()` ને પહેલેથી ગરમ કરે છે, જેથી આઇટમ્સ સ્ક્રીને પહોંચે તે પહેલાં જ અનુવાદિત થઈ જાય; તેને ચાલુ કરવાથી કૅનવાસ સાફ થઈને ફરી પેઇન્ટ થાય છે.
9. **સ્ટોરેજ કીઝ**: `uiTranslate{Enabled,Provider,Lang,Model,ApiUrl,ApiKey,Thinking,Cache,Onboarded}`. **સેટિંગ્સ UI**: એક જ પહેલા-સ્તરનું "AI લક્ષણો" પેજ (`lib/pages/setting/ui_translate/`), AI વિડિયો સારાંશ અને AI અનુવાદ માટે સ્વતંત્ર બ્લોક્સ સાથે.

**વિશ્વવ્યાપી CDN (`VideoUtils.getCdnUrl`).** સ્ટ્રીમ URL સાઇન કરેલા હોય છે, અને કોઈ URL ના હોસ્ટને ફરી લખવાથી તે 403 સાથે નકારાઈ જાય છે — એટલે પ્લેબેક ક્યારેય હોસ્ટ ફરી લખતું નથી. PiliBabel એ URL પરત આપે છે જે bilibili ક્લાયન્ટના IP ને જિયો-રૂટેડ રીતે આપે છે, અને જ્યારે ઉમેદવાર યાદીમાં પહેલેથી જ કોઈ ઓવરસીઝ એજ (`*.akamaized.net`, `mirror(cos|ali|hw)ov`, `cn-hk-eq-bcache`) હોય, તો તેને પ્રાધાન્ય મળે છે. ડાઉનલોડમાં, જ્યાં હોસ્ટ બદલવો સલામત છે, ત્યાં ગ્લોબલ Akamai એજને વધારાનું પ્રાધાન્ય મળે છે અને કોઈ લાઇન અટકે કે રિઝ્યુમનો ઇનકાર કરે ત્યારે પછીના સાઇન થયેલા ઉમેદવાર પર ફરજાય છે. કાચા `/v/resource` P2P લિંક્સ 404 ટાળવા માટે હજુ પણ હાલના રિલે પર પરત ફરે છે.

**ડિઝાઇન સોદાઓ / જાણીતી મર્યાદાઓ.** સ્ટ્રિંગ્સને રિસોર્સમાં કાઢવાને બદલે તેમની જગ્યાએ જ લપેટવામાં આવેલ હોવાથી, કેટલાક `Text` ન હોય તેવા સ્ટ્રિંગ પૅરામીટર્સ અને કેટલાક રિચ-ટેક્સ્ટ સ્પાન્સ હજુ પણ ધીમે ધીમે ભરાઈ રહ્યા છે. **લૉજિક કીઝ** તરીકે કામ કરતી સ્ટ્રિંગ્સ (`==` સાથે સરખામણી થતી, `简介` જેવા ટૅબ નામ તરીકે વપરાતી, અથવા સ્વિચમાં વપરાતા enum લેબલ્સ) વર્તન ન તૂટે એ માટે જાણીજોઈને **આખી લપેટાતી નથી**. ડાનમાકુ અનુવાદ સરકતા કૅનવાસ પર શ્રેષ્ઠ-પ્રયાસ છે — અતિ ગીચ ડાનમાકુમાં અનુવાદ આવે તે પહેલાં તમે થોડી ક્ષણ મૂળ ટેક્સ્ટ જોઈ શકો છો. અનુવાદ માટે નેટવર્ક જોઈએ; વિના તેના, બિન-ચાઇનીઝ લક્ષ્યો અસરમાં આવતા નથી. બિલ્ટ-ઇન એન્ડપોઇન્ટ bilibili ચલાવતી એક મફત જાહેર સેવા છે — તે ક્યારેય રેટ-લિમિટ થાય કે ઉપલબ્ધ ન રહે, તો એપ તમને જણાવે છે અને તમે તમારા પોતાના API પર જઈ શકો છો.

## વારસામાં મળેલી લક્ષણ યાદી (PiliNara / PiliPlus માંથી)

નીચેનું બધું PiliNara માંથી (અને પરોક્ષ રીતે, PiliPlus માંથી) લાવેલું છે; PiliBabel તેની ઉપર AI અનુવાદ લેયર ઉમેરે છે.

**UI અને પ્લેટફોર્મ અનુકૂલન**
- [x] ઘણા ક્લાયન્ટ સાથે રહી શકે એ માટે પ્લેટફોર્મ પ્રમાણે એપનું નામ બદલ્યું (PiliBabel, PiliNara સાથે સાથે ઇન્સ્ટોલ થાય છે)
- [x] Xiaomi HyperOS મિનિ-વિન્ડો હેઠળ Flutter રેન્ડરિંગ સુધારો ([#161086](https://github.com/flutter/flutter/issues/161086), [venera#467](https://github.com/venera-app/venera/pull/467) મારફત); Android પર પ્રિડિક્ટિવ બેક એનિમેશન
- [x] વૈયક્તિકૃત કરી શકાય તેવો "મારું" કાર્ડ ક્રમ/સંખ્યા; ઇતિહાસ-કાર્ડ પ્રીવ્યૂ અને "પછી જુઓ" વિભાગો
- [x] ગોઠવી શકાય તેવી ટ્રિગર પહોળાઈ સાથે ઑટો સાઇડબાર બદલી; લૉંગ-પ્રેસ / જમણું-ક્લિક માંથી ઇમેજ-કૉપિ; મોટું MD3E શૈલી રિફ્રેશ

**ફોન્ટ સિસ્ટમ** — સામગ્રી-હેશ ડી-ડુપ્લિકેશન સાથે એકીકૃત ઇમ્પોર્ટ પૂલ, ડાનમાકુ ફોન્ટ એ જ પૂલમાં ભેગા, ttc આધાર સાથે `loadFontFromList`, અને શુદ્ધ-ASCII હેશ ફેમિલી નામો.

**પ્લેબેક, મિનિ-વિન્ડો અને ગુણવત્તા** — એપ-અંદર મિનિ-વિન્ડો (ડ્રૅગ, રિસાઇઝ, SponsorBlock સ્કિપ, ઑટો સિસ્ટમ PIP, લાઇવ સેલ્ફ-રેસ્ક્યુ બાર), સમાંતર-ઓડિયો પ્લેબેક, 200% સુધી એપ-અંદર વૉલ્યુમ, લેટન્સી ટેસ્ટ સાથે કસ્ટમ વિડિયો CDN ડોમેઇન અને પ્રાદેશિક નોડ પસંદગી, અલગ હાફ/ફુલ-સ્ક્રીન ડિફૉલ્ટ ગુણવત્તા, ઉપર-સ્વાઇપ સ્પીડ લૉક, ટૅબ્લેટ કીબોર્ડ કંટ્રોલ, લાઇવ SuperChat ટાઇમસ્ટેમ્પ, ફૅન-ઇન્ટિમસી માટે લાઇવ હાર્ટબીટ.

**સબટાઇટલ, AI અને ઑફલાઇન** — સ્વતંત્ર સેકન્ડરી-સબટાઇટલ સ્ટાઇલિંગ સાથે દ્વિભાષી સબટાઇટલ, AI સબટાઇટલ વિશ્લેષણ (કસ્ટમ OpenAI-સુસંગત એન્ડપોઇન્ટ, ટાઇમસ્ટેમ્પ જમ્પ, ટેમ્પલેટ, સાચવાયેલી વાતચીત, સૉફ્ટ સબટાઇટલ-નથી ફૉલબૅક), WEBVTT/SRT એક્સપોર્ટ, ફોલ્ડર મેનેજમેન્ટ અને મેટાડેટા સ્થિરતા સાથે ઑફલાઇન-કૅશ ડ્યુઅલ વ્યૂ, ડાઉનલોડને જાહેર Download ફોલ્ડરમાં એક્સપોર્ટ (Android).

**ડાનમાકુ અને બ્લૉકિંગ** — વધુ સારી મર્જ-ડાનમાકુ સ્કેલિંગ ([Pakku.js](https://github.com/xmcp/pakku.js)-શૈલી), ઇમ્પોર્ટ/એક્સપોર્ટ સાથે યાદી-આધારિત વિઝ્યુઅલ regex બ્લૉકિંગ, SponsorBlock સેગમેન્ટ-અંદર-જવાનું સ્કિપ, ગૉસિયન-કર્નલ હાઇ-એનર્જી પ્રોગ્રેસ બાર.

**ભલામણ / ડાયનેમિક / ટિપ્પણી ફિલ્ટરિંગ** — શીર્ષક/UP/ચૅનલ કીવર્ડ, સમયગાળો, પ્લે-ગણતરી, લાઇક-દર, ફૉલો-થયેલા-UP મુક્તિ, બિનસત્તાવારી/માત્ર-પેઇડ ફિલ્ટરિંગ, સહિત વ્હાઇટલિસ્ટ, કૉમર્સ/બિનસત્તાવારી ડાયનેમિક્સ, UP-પોતાની-ટિપ્પણી અને પિન-થયેલી-ટિપ્પણી મુક્તિઓ, App+Web મર્જ-ફીડ મોડ.

**ડાયનેમિક્સ, શોધ અને વપરાશકર્તા માહિતી** — UP માટે કસ્ટમ નોટ્સ, 13 નામ-સ્લૉટમાં નોટ-નિકનેમ-બદલે, સ્વતંત્ર નેસ્ટેડ-ટિપ્પણી સૉર્ટ, સ્થાનિક કીવર્ડ શોધ ફિલ્ટર, b23.tv શૉર્ટ-લિંક જમ્પ, માત્ર-પેઇડ બૅજ, ભલામણ-કારણ-છુપાવો ટૉગલ, કૉઇન XP ડિસપ્લે.

**લાઇવ સુધારા** — ફૅન-મેડલ પહેરવાનું પૅનલ, HLSને પ્રાધાન્ય આપતું DLNA કાસ્ટ, SuperChat સમય ડિસપ્લે, સેલ્ફ-રેસ્ક્યુ માટે મિનિ-વિન્ડો નીચેની કંટ્રોલ પટ્ટી.

**સિસ્ટમ ઇન્ટિગ્રેશન અને ડેસ્કટૉપ** — Windows SMTC, Linux MPRIS (`audio_service_mpris`), ફરી બનાવેલી ઑડિયો-ફોકસ હૅન્ડલિંગ.

## અસ્વીકરણ

PiliBabel એક વ્યક્તિગત, રુચિ-આધારિત પ્રોજેક્ટ છે, **ફક્ત શીખવા અને ટેસ્ટિંગ માટે** આપવામાં આવે છે; કૃપા કરીને ડાઉનલોડના **24 કલાકની અંદર** તેને ડિલીટ કરી દો.

- PiliBabel એક **બિનસત્તાવારી થર્ડ-પાર્ટી** ક્લાયન્ટ છે અને **bilibili સાથે સંલગ્ન, મંજૂર કે પ્રાયોજિત નથી**.
- બધી API અધિકૃત જાહેર એન્ડપોઇન્ટ્સ માંથી એકત્રિત કરેલી છે; **ક્રેક કરેલી, ઓવર-પ્રિવિલેજ્ડ, કે પેવૉલ-બાયપાસ કરતી કોઈ સામગ્રી આપવામાં આવતી નથી**.
- **AI અનુવાદ એક થર્ડ-પાર્ટી મોડેલ એન્ડપોઇન્ટ પર ચાલે છે.** ડિફૉલ્ટ રૂપે તે bilibili ની પોતાની મફત જાહેર Index-Translate સેવા છે; જો તમે પોતાના API પર જાઓ, તો તે તમે ગોઠવેલો એન્ડપોઇન્ટ છે. અનુવાદની ગુણવત્તા અને પાલનની જવાબદારી વપરાશકર્તા અને પસંદ કરેલા મોડેલ પ્રોવાઇડરની છે; આ પ્રોજેક્ટ **કોઈ મોડેલ કે API કી હોસ્ટ કરતું નથી**.
- કૉપિરાઇટ અને bilibili ની સેવા શરતોનો આદર કરો. જવાબદારીપૂર્વક ઉપયોગ કરો.

તેમના ઓપન-સોર્સ સમર્પણ માટે મૂળ અને અપસ્ટ્રીમ લેખકો પ્રત્યે આદરપૂર્વક:
- [guozhigq/pilipala](https://github.com/guozhigq/pilipala)
- [orz12/PiliPalaX](https://github.com/orz12/PiliPalaX)
- [bggRGjQaUbCoE/PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)
- [Starfallan/PiliNara](https://github.com/Starfallan/PiliNara) — PiliBabel નો સીધો મૂળ પ્રોજેક્ટ
- [bilibili/Index-Translate](https://github.com/bilibili/Index-Translate) — ઓપન-સોર્સ અનુવાદ મોડેલ કુટુંબ જેને બિલ્ટ-ઇન એન્જિન કૉલ કરે છે

કોઈ સામગ્રી તમારા અધિકારોનું ઉલ્લંઘન કરતી હોય, તો દૂર કરાવવા માટે અમારો સંપર્ક કરો.
