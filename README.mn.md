> **Анхааруулга.** PiliBabel бол **албан бус, нээлттэй эх кодтой, гуравдагч талын** клиент. Энэ нь bilibili / bilibili Inc.-тэй **ямар ч холбоогүй, тэдний дэмжлэг, ивээн тэтгэлэггүй**. Бүх API нь албан ёсны нийтийн endpoint-оос авдаг; **ямар ч төлбөртэй контент нээгдэхгүй, хагарахгүй**. Бүрэн [Анхааруулга](#анхааруулга) ба [Лиценз](#лиценз) хэсгийг уншина уу.

## PiliBabel гэж юу вэ?

PiliBabel бол [PiliNara](https://github.com/Starfallan/PiliNara) дээр бүтээсэн **бие даасан гуравдагч талын fork** бөгөөд PiliNara-гийн өвлөсөн бүхнийг өвлөнө:

```
bilibili (албан ёсны нийтийн API)
        ↓
   PiliPala / PiliPalaX        — анхны төсөл
        ↓
   PiliPlus                    — идэвхтэй fork
        ↓
   PiliNara                    — PiliPlus-ийн fork (хувийн өөрчлөлт)
        ↓
   PiliBabel  ← та энд байна   — PiliNara-гийн fork
```

PiliBabel нь **PiliNara / PiliPlus-ийн бүх боломжийг** хадгалж (доорх [өвлөгдсөн боломжуудын жагсаалт](#өвлөгдсөн-боломжуудын-жагсаалт-pilinara--piliplus-аас)-ыг үзнэ үү), дээд талын клиентүүдэд байхгүй **хоёр гол боломж** нэмнэ:

> **AI интерфейс ба контентын орчуулга** — бүхэл апп (UI шошго, видеоны гарчиг, UP-ийн нэр, сэтгэгдэл, динамик, feed, тэр ч байтугай шууд данмаку) **таны** сонгосон хэлээр харагдана.

1.0-ээс хойш энэ нь **шууд ажилладаг**: орчуулгын модель **дотроо багтсан**. bilibili өөрийн орчуулгын модель бүлгээ [Index-Translate](https://github.com/bilibili/Index-Translate) нэрээр нээлттэй болгож, үнэгүй нийтийн endpoint-оос үйлчилдэг. PiliBabel түүн рүү чиглүүлсэн байдаг тул апп суулгамагц орчуулга ажиллана — бүртгэлгүй, түлхүүргүй, төлбөргүй. Өөрийн моделоо ашиглахыг хүсвэл өөрийн API-ийн зам бас нэг товшилтын зайд байна.

> **Чихэвчинд үнэхээр синхрон үлддэг аудио** — Bluetooth эсвэл утастай чихэвчинд дуу зурагтайгаа хамт явна. Албан ёсны апп үүнийг зөв хийдэг; PiliNara ба PiliPlus шууд тийм биш. PiliBabel одоо mpv-ээс **AudioTrack**-ыг эхэлж асуудаг бөгөөд энэ нь албан ёсны клиент шиг аудио гаралтын хоцролтыг *хэмждэг* — зөвхөн *тооцдог* **OpenSL ES**-ээс ялгаатай.

## Гол боломжууд

- **Чихэвчний аудио синхрон.** Тоглуулагч одоо анхдагчаар mpv-гийн **AudioTrack** backend-ийг ашиглана (дараалал `audiotrack,aaudio,opensles`), **OpenSL ES** биш. AudioTrack нь *хэмжсэн* гаралтын хоцролтыг мэдээлдэг — тоглосон фрэймийн тоо болон төхөөрөмжийн presentation timestamp-ыг уншдаг бөгөөд албан ёсны bilibili апп болон Android-ы өөрийнх нь `MediaSync` яг ингэж зураг, дууг хамт барина. OpenSL ES зөвхөн *тооцоолдог* байсан тул Bluetooth чихэвчинд аудио цаг гулсаж, зураг эрт харагддаг байв. Туршилтад энэ хоцролт бараг бүрэн арилсан. Тохиргоо → Видео → Аудио гаралтын төхөөрөмж дээр хүссэн үедээ өөрчилж болно.
- **AI орчуулга, хаа сайгүй.** Навигацийн табууд, видеоны карт, дэлгэрэнгүй хуудас, сэтгэгдэл, динамик, мөн Миний / Дуртай / Түүх / Зурвас / Хайлт бүх гадаргуу — нэг ерөнхий шүүрэл **1,650+ UI мөр**-ийг хамарч, динамик контент (гарчиг, зохиогчийн нэр, үйлдлийн тоо)-ыг ч бас орчуулна.
- **Хоёр хөдөлгүүр, нэг унтраалга.** **Дотоод** (анхдагч) нь bilibili-гийн албан ёсны **Index-Translate-35B-A3B** үнэгүй endpoint-ыг ашиглана — тохируулах зүйл байхгүй. *Өөрийн API* нь өмнөх зан төлөвийг хадгална: дурын OpenAI-д нийцэх `/chat/completions` endpoint руу өөрийн base URL / key / model-оор зааж өгнө. AI видео хураангуй болон AI орчуулга нь **бүрэн тусдаа** endpoint, тохиргоотой бөгөөд хоёулаа нэг **"AI боломжууд"** хуудсанд байрлана.
- **Нэг хэлний жагсаалт, хоёр хөдөлгүүрт.** Зорилтот хэлний жагсаалт хөдөлгүүрээр хуваагддаггүй — аль хөдөлгүүрийг сонгосон ч ижил жагсаалт санал болгоно. Энэ нь bilibili-гийн албан ёсны моделийн **151 хэл**-ийг түүнд байхгүй **6 хэл**-тэй нэгтгэнэ — Уламжлалт Хятад, Хялбар ба Уламжлалт Ву, эх газрын ба Тайваний Хоккиен, мөн Жуан. Бүс нутгийн болон бичгийн хувилбаруудыг **тусад нь** үлдээдэг — Марокко / Египет / Нажди / Левантийн Араб тус тусдаа сонголт, мөн Кирилл-Латин Серб, Узбек, Урду ч мөн адил.
- **Хамрах хүрээний талаар шударга.** Албан ёсны жагсаалт доторх хэлнүүдийг bilibili-гийн модель хамарна. Гаднах цөөн хэл — Уламжлалт Хятад, Хялбар ба Уламжлалт Ву, эх газрын ба Тайваний Хоккиен ба Жуан — жагсаалтад байсаар байгаа ч тэмдэглэгдсэн тул илүү сайн үр дүн өөрийн модель шаардаж болзошгүйг шууд харна.
- **Нэг удаа орчуулна, дараа нь тогтсон.** Эх мөр бүр **яг нэг удаа** орчуулагдаж, үр дүн нь локалд хадгалагдана. Дэлгэцээ дахин нээхэд **хэзээ ч дахин орчуулахгүй** — албан ёсны клиенттэй ижил зарчим, тогтвортой, урьдчилан таамаглах боломжтой орчуулга.
- **Сэтгэгдэл бүрд Эх ⇄ Орчуулга унтраалга** (жижиг дүрс, хятад үг биш). `@дуудалт / [emoji] / #сэдэв# / холбоос` нь токен хэвээр хадгалагдаж, **гипер холбоос агуулсан сэтгэгдэл ч холбоосоо дарагдах хэвээр үлдэнэ**.
- **Данмаку (弹幕) орчуулга** — тоглуулагчийн баруун дээд удирдлагын эгнээний тусдаа унтраалга, **анхдагчаар унтарсан** бөгөөд баталгаажуулалтын дараа ажиллана (түүний текст ч орчуулагдана). Асаасны дараа тоглуулах толгойн өмнөх данмаку **~15 секундын багц**-аар урьдчилан орчуулагдана (дунд руу гүйлгэх нь зөв ажиллана, эхнээс биш), тул дэлгэцэд гарах үед орчуулга ихэвчлэн бэлэн болсон байна.
- **Thinking горимын унтраалга** (`enable_thinking`) — чанар ба хурдны сонголт, дээр нь тохиргоо дахь **"орчуулга турших"** ба **"кэш цэвэрлэх"** товчнууд.
- **Хурдан хэл солих**: хязгаарлагдмал зэрэгцээтэй багц хүсэлт, байнгын кэшийн эсрэг; хэл солиход одоогийн дэлгэц нэг удаа дахин бүтээгдэх тул орчуулагдаагүй текст рүү харж үлдэхгүй. AI орчуулгыг унтраавал бүх UI эх текст рүү буцаж, огт хүсэлт явуулахгүй.
- **Анхны нээлтийн танилцуулга.** Аппыг анх нээхэд англи хэл дээрх цонх орчуулгыг асаахыг санал болгоно. Зөвшөөрвөл орчуулга асаж, дотоод модель сонгогдож, AI тохиргооны хуудас нээгдээд ямар хэл хүсэхээ шууд асууна — ингэснээр шинэ хэрэглэгч суулгаснаас хоёр товшилтын дотор орчуулагдсан апп руу шилжинэ.
- **Дэлхий даяар ажилладаг тоглуулалт.** PiliBabel нь bilibili-гийн geo-route хийсэн `playurl` аль хэдийн санал болгодог гадаад edge (глобал **Akamai**, `mirror*ov`, `cn-hk-eq-bcache`)-ийг сонгодог бөгөөд таныг эх газрын (Aliyun/Shenzhen) зангилаанд хадаж үлдээхгүй — ингэснээр эх газрын Хятадаас гаднах хэрэглэгчид "аудио үргэлжилж, видео хөлдөх" зовлонд орохгүй. Тохиргооноос CDN-ийг гараар ч түгжиж болно.
- **"Загвар ба өнгө" хуудас, Material You хэв маяг.** Гэрэлтэй / харанхуй / системийг дагах нь **гурван амьд урьдчилсан харах карт**-аас сонгогдоно — карт бүр тухайн горимд яг ямар өнгөөр харагдахыг бодит интерфейсийн жижиг хувилбараар үзүүлнэ ("системийг дагах" карт нь диагональ хуваагдсан, гэрэлтэй нь харанхуй дээр). Доор нь: **динамик өнгө** (төхөөрөмж дэмжвэл системийн ханын зургаас авна), **өндөр контраст харанхуй** (цэвэр хар гадаргуу, шөнө нүдэнд ээлтэй) ба **үргэлж харанхуй тоглуулагч**. Өнгөний хэсэг нь бүрэн FlexScheme палитрыг хадгална — **19 seed өнгө** дээр нэмээд салангид **"палитр загвар"** нь seed-ээс контейнерийн өнгө бүр хэрхэн гарахыг тодорхойлно.
- **LXGW WenKai апптай хамт ирнэ.** **LXGW WenKai (霞鹜文楷)** үсгийн фонт **багцлагдсан бөгөөд анхдагчаар тавигдсан** — дулаан, уншихад хялбар хятад фонт суулгамагц бэлэн, сонгогчоос хайх шаардлагагүй. Энэ нь бүх интерфейс *болон* данмакуд үйлчилнэ. Системийн фонт руу буцах, суусан дурын системийн фонт сонгох, эсвэл өөрийн `.ttf` / `.otf` / `.ttc` оруулах боломжтой; өмнө нь тодорхой сонгосон фонт шинэчлэлтийн дараа ч хадгалагдана. Зузаан, хэмжээ өмнөх шигээ тохируулагдана.

## Офлайн аудио кэш ба локал руу татах (PiliBabel-д онцгой)

Дээд талын PiliNara / PiliPlus-д байхгүй хоёр боломж — хоёулаа медиагаа офлайнаар үнэхээр эзэмшихэд чиглэсэн.

### Аудио кэш (зөвхөн аудио замыг хадгалах)

- **Видео биш, зам.** Видео хуудасны цэсэнд *Аудио кэш* нь *Видео кэш*-ийн яг доор байрлана; видео сонсох хуудасны дээд баарны баруун дээд хэсэгт байрлах эрэмбэлэх / унтраах таймер / бусад товчнуудын зүүн талд ч тусдаа *Аудио кэш* товч бий.
- **Чацрын түвшинг сонгоно.** Hi-Res lossless, Dolby Atmos, 192K, 132K эсвэл 64K — видеоны чацрын сонгогчтой ижил жагсаалт.
- **Эх контейнер, транскодгүй.** Файл нь CDN-ээс ирсэн хэвээр бичигдэнэ: `m4a`, `mp3`, `flac`, `wav`, `aac` эсвэл `ogg`.
- **Тусдаа модуль.** Кэшийн хуудас *Кэшлэгдсэн видео* / *Кэшлэгдсэн аудио* гэж хуваагдаж, өмнө байсан модулиа санана.
- Кэшлэгдсэн аудио дээр дарахад шууд аудио тоглуулагч нээгдэнэ; нэг нэгээр эсвэл бөөнөөр устгаж болно.

### Локал хавтас руу татах

- **Тусдаа цэсийн мөр.** *Локал руу татах* нь видео хуудасны цэсэн дэх бие даасан мөр бөгөөд *Аудио кэш*-ийн яг доор — апп дотор кэшлэх ба өөрийн хавтас руу хадгалах нь хоёр өөр үйлдэл.
- **Видео татах эсвэл аудио татах.** Эхлээд алийг нь татахыг, дараа нь чацрын түвшинг (видео чанар / аудио чанар) асууна.
- **Таны хавтас, таны дүрэм.** Системийн файл менежерээр дурын хавтас сонгоно (Тохиргоо → *Локал руу татах байршил*), хүссэн үедээ сольж эсвэл цэвэрлэж болно. Хараахан сонгоогүй бол хавтасны сонгогч тэр дороо нээгдэнэ.
- **Шууд тоглуулж болох файл.** Видеог нэг мукслагдсан урсгал (`fnval=1`) хэлбэрээр татдаг тул дискэн дээр ямар ч тоглуулагчид өгч болох энгийн MP4 үлдэнэ.
- **Аудио эх форматаа хадгална** — транскодгүй, апп доторх кэштэй яг адил.
- Файлууд видеоны гарчгаар нэрлэгдэж, байгаа таталтыг хэзээ ч дарж бичихгүй.

## Хоёр орчуулгын хөдөлгүүр

| | Дотоод (анхдагч) | Өөрийн API |
|---|---|---|
| Модель | bilibili **Index-Translate-35B-A3B** | OpenAI-д нийцэх дурын |
| Endpoint | `index-translate.bilibili.com/v1` | таны base URL |
| API түлхүүр | **шаардлагагүй** | өөрийн |
| Зардал | үнэгүй | нийлүүлэгчийн тариф |
| Хүсэлт | нэг хүсэлтэд нэг мөр | багцласан (≤ 16 / хүсэлт) |
| Нэмэлт хэл | — | таны модель мэдэх дурын хэл |

**Дотоод хөдөлгүүрт яагаад нэг хүсэлтэд нэг мөр вэ.** Index-Translate бол орчуулгын *мэргэжилтэн* бөгөөд зохиогчдын баримталдаг дуудлагын загвар нь нэг зүйлийн template ("дараах текстийг X рүү орчуул, зөвхөн орчуулгыг гарга"). Тиймээс PiliBabel энэ хөдөлгүүр дээр өөрийн API-д хэрэглэдэг дугаарласан жагсаалт/JSON массив багц prompt биш, нэг хүсэлтэд нэг мөр явуулдаг. Endpoint үнэгүй тул багц гаралтад найдах нь ямар ч ашиггүй — энэ бол цөөн хүсэлт илүү гаргахын оронд бүтэлгүйтэх зам багасгах санаатай сонголт.

**0.3.x-ээс шинэчлэх.** Таны өөрийн API тохиргоо — base URL, түлхүүр, модель — **тохируулсан хэвээр үлдэнэ**. Хөдөлгүүрийн сонголт зүгээр л дотоод модель руу буцах тул шинэчилсний дараа анх нээхэд bilibili-гийн үнэгүй модель дээр байх болно; *Тохиргоо → AI → AI боломжууд → орчуулгын хөдөлгүүр* руу орж *Өөрийн API* руу буцаавал өмнөх тохиргоо тэр дороо эргэн ирнэ.

## AI интерфейсийн орчуулга хэрхэн ажилладаг (техник)

Энэ репод **i18n / ARB нөөцийн давхарга байхгүй** — UI мөрүүд нь хятад хэлээр шууд бичигдсэн. Widget бүрийг дахин бичихийн оронд PiliBabel дээр нимгэн орчуулгын давхарга нэмсэн:

1. **Глобал хайлтын wrapper.** `lib/services/ui_translate/` нь дээд түвшний `uiTx(String src)`-ийг гаргана. `Text('中文')` байсан widget текст `Text(uiTx('中文'))` болно. **codemod** скрипт (`tool/ui_translate_*.py`) үүнийг бүх төслөөр хэрэглэсэн — ойролцоогоор **223 файл / 1,650+ мөр** — шаардлагатай газраа хүчингүй болсон `const` түлхүүр үгийг автоматаар хасч (жишээ нь `const X<T>(...)` ерөнхий хэлбэр болон `const Positioned.fill(...)` гэх мэт цэгтэй нэрс), `static const` list/map зарлалыг `static final` болгож хөрвүүлсэн.
2. **`GetxService` цөм** (`ui_translate_service.dart`):
   - байнгын **эх → орчуулга** кэш (GetStorage дээр суурилсан), тул мөр бүр нэг удаа орчуулагдаж, үүрд дахин ашиглагдана;
   - `tx()` эхлээд `RxInt revision`-ыг уншаад шийднэ: унтарсан бол → эхийг буцаана; зорилтот нь **Хялбар Хятад (`zh-CN`)** бол API хүсэлтгүйгээр эхийг буцаана (bilibili-гийн эх контент бараг бүхэлдээ Хялбар Хятад). Бусад бүх зорилт — Уламжлалт Хятад, Кантон, Ву/Шанхай, Хоккиен/Мин Нан ч — тохируулсан хөдөлгүүрээр явна; зөвхөн Хятад хэлний бүлэгт хамаарах нь орчуулгыг алгасахгүй. Дараа нь кэшээс эсвэл **дараалалд** тавина;
   - дараалалд орсон мөрүүдийг **ажилчин пул** **багц бүрээр аажмаар хэрэглэх** замаар гаргана (буцаж ирсэн багц бүр `revision`-ыг нэмэгдүүлж, текст аажмаар шинэчлэгдэнэ), үр дүнг **хадгална** (хязгаарлалттай). Багцын хэмжээ, зэрэгцээ нь хөдөлгүүрээс хамаарна: дотоод модельд **нэг хүсэлтэд 1**, өөрийн API-д **≤ 16, зэрэгцээд ≤ 10**.
3. **Хөдөлгүүрийн шийдвэр.** `TranslateProvider` (`builtin` / `custom`) аль URL, түлхүүр, моделиор явуулахыг шийднэ; бусад талаараа хоёр хөдөлгүүр нэг кодын зам, нэг хэлний жагсаалтыг хуваалцдаг тул хөдөлгүүр солих нь нэг тохиргооны асуудал бөгөөд хэзээ ч өөр боломжийн багц болохгүй.
4. **Тээвэр** нь AI видео хураангуйтай ижил баталгаажсан **streaming** сувгийг дахин ашиглана — `AiChatService.streamChat` → `{base}/chat/completions` ба `stream: true` (зөвхөн streaming дэмждэг gateway-тай нийцнэ) — орчуулга өөрийн `apiUrl` / `apiKey` / `model` ба `enable_thinking` туг ашиглаж болохоор өргөтгөсөн. Өөрчлөлт нь **буцаж нийцэхүйц** тул видео хураангуй хэвээр ажиллана.
5. **Орлуулагчтай өгүүлбэр** нь `uiTxP(template, args)` ашиглана: `{0}`/`{1}` орлуулагчтай бүтэн өгүүлбэрийг нэг тогтвортой түлхүүрээр орчуулж (prompt нь орлуулагчийг хадгалахыг модельд зааварлана), дараа нь утгуудыг буцааж тавина — ингэснээр `共 {0} 条` хэв маягтай мөрүүд динамик хэсгээ гэмтээхгүйгээр орчуулагдана.
6. **Хэлний хүснэгт** (`app_language.dart`): `AppLanguage` бүр харуулах автоним, бичиг/бүс нутгийн дүрмийг кодчилсон `toModel` prompt мөр, мөн bilibili-гийн албан ёсны жагсаалт түүнийг хамарч байгаа эсэхийн туг агуулна. Бичгийн дүрэм (Хялбар ба Уламжлалт, аялгын тогтвортой байдлын заавар) модельд зөвхөн prompt-оор хүрч, клиент дээрх детерминист нормалчлалын шат дараа нь зөрүүтэй glyph-үүдийг засна.
7. **Сэтгэгдэл** нь `uiTxComment(text, id)`-ээр явж, `@ / [emoji] / #сэдэв# / холбоос`-ыг хөндөхгүй токен хэвээр үлдээнэ; холбоос агуулсан rich-text span-ууд холбоос танигчаа хадгалан орчуулагдаж, сэтгэгдлийн id-ийн олонлог нь Эх ⇄ Орчуулга унтраалгыг удирдана.
8. **Данмаку** (`danmaku/view.dart`): унтраалга асаалттай үед байрлалын сонсогч `[playhead, playhead + 15s]`-ийг секунд тутам алхаж, данмаку бүрийн агуулга дээр `uiTx()`-ийг урьдчилан дуудна, ингэснээр зүйлс дэлгэцэд хүрэхээс өмнө орчуулагдана; асаах нь canvas-ыг цэвэрлэж дахин зурна.
9. **Хадгалах түлхүүрүүд**: `uiTranslate{Enabled,Provider,Lang,Model,ApiUrl,ApiKey,Thinking,Cache,Onboarded}`. **Тохиргооны UI**: нэг нэгдүгээр түвшний "AI боломжууд" хуудас (`lib/pages/setting/ui_translate/`) дотор AI видео хураангуй ба AI орчуулгын тусдаа блок.

**Дэлхий даяар CDN (`VideoUtils.getCdnUrl`).** Урсгалын URL нь гарын үсэгтэй бөгөөд URL-ийн host-ыг дахин бичихэд 403-аар татгалздаг — тиймээс тоглуулалт host-ыг хэзээ ч дахин бичихгүй. PiliBabel нь bilibili клиентийн IP-д өгсөн geo-route URL-ыг буцаана, харин кандидатын жагсаалтад гадаад edge (`*.akamaized.net`, `mirror(cos|alix|hw)ov`, `cn-hk-eq-bcache`) байвал түүнийг илүүд үзнэ. Host солих нь аюулгүй таталтын хувьд нэмж глобал Akamai edge-ийг илүүд үзэж, шугам гацах эсвэл resume-ыг татгалзвал дараагийн гарын үсэгтэй кандидат руу эргэлдэнэ. `/v/resource`-ийн түүхий P2P холбоос 404-өөс зайлсхийхээр одоо байгаа relay руу буцсаар байна.

**Дизайны сонголт / мэдэгдэж буй хязгаар.** Мөрүүдийг нөөц рүү гаргахын оронд байранд нь боосон тул цөөн `Text` бус мөрийн параметр болон зарим rich-text span аажмаар нэмэгдсээр байна. **Логикийн түлхүүр** болж бас ажилладаг мөрүүд (`==`-ээр харьцуулдаг, `简介` гэх мэт tab нэр болж хэрэглэгддэг, switch-д хэрэглэгддэг enum шошго) нь зан төлөв эвдрэхээс зайлсхийх үүднээс **санаатайгаар** бүхэлд нь боогүй. Данмаку орчуулга нь гүйлгэх canvas дээрх хамгийн сайн хүчин чармайлт — маш нягт данмакуд орчуулга ирэхээс өмнө эхийг нь богино хугацаанд харж болно. Орчуулгад сүлжээ хэрэгтэй; сүлжээгүй бол Хятад бус зорилтууд огт хүчин төгөлдөр болохгүй. Дотоод endpoint нь bilibili-гийн ажиллуулдаг үнэгүй нийтийн үйлчилгээ — хэрэв хязгаарлагдах эсвэл боломжгүй болвол апп танд мэдэгдэж, өөрийн API руу шилжиж болно.

## Анхааруулга

PiliBabel бол хувийн, сонирхолд тулгуурласан төсөл бөгөөд **зөвхөн суралцах, турших зорилгоор** үзүүлнэ; татаж авснаас хойш **24 цагийн дотор** устгана уу.

- PiliBabel бол **албан бус гуравдагч талын** клиент бөгөөд **bilibili-тэй холбоогүй, тэдний дэмжлэг, ивээн тэтгэлэггүй**.
- Бүх API нь албан ёсны нийтийн endpoint-оос авдаг; **хагарсан, хэт эрхтэй эсвэл paywall давах контент** үзүүлэхгүй.
- **AI орчуулга нь гуравдагч талын модель endpoint дээр ажиллана.** Анхдагчаар энэ нь bilibili-гийн өөрийн үнэгүй нийтийн Index-Translate үйлчилгээ; өөрийн API руу шилжвэл таны тохируулсан endpoint. Орчуулгын чанар ба нийцлийн хариуцлага нь хэрэглэгч ба сонгосон модель нийлүүлэгчид хамаарна; энэ төсөл **модель ч, API түлхүүр ч** байрлуулахгүй.
- Зохиогчийн эрх ба bilibili-гийн үйлчилгээний нөхцлийг хүндэтгэнэ үү. Хариуцлагатай ашиглаарай.

Анхны болон дээд талын зохиогчдын нээлттэй эхийн зориулалтад хүндэтгэлтэй:
- [guozhigq/pilipala](https://github.com/guozhigq/pilipala)
- [orz12/PiliPalaX](https://github.com/orz12/PiliPalaX)
- [bggRGjQaUbCoE/PiliPlus](https://github.com/bggRGjQaUbCoE/PiliPlus)
- [Starfallan/PiliNara](https://github.com/Starfallan/PiliNara) — PiliBabel-ийн шууд эцэг төсөл
- [bilibili/Index-Translate](https://github.com/bilibili/Index-Translate) — дотоод хөдөлгүүрийн дууддаг нээлттэй орчуулгын модель бүлэг

Хэрэв ямар нэг контент таны эрхийг зөрчвөл устгуулах хүсэлтээр бидэнтэй холбогдоно уу.
