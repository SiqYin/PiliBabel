> **ئىزاھات.** PiliBabel — **رەسمىي ئەمەس، ئوچۇق كودلۇق، ئۈچىنچى تەرەپ** خېرىدارى. ئۇ **bilibili / bilibili Inc. بىلەن مۇناسىۋەتسىز، ئۇلار تەرىپىدىن تەستىقلانمىغان ۋە ئۇلار تەرىپىدىن ئىقتىسادىي قوللاشقا ئېرىشمىگەن**. بارلىق API رەسمىي ئاممىۋى ئېندپوئىنتلاردىن يىغىلغان؛ **ھېچقانداق ھەقلىق مەزمۇن ئېچىۋېتىلمەيدۇ ياكى يېشىلمەيدۇ**. تولۇق [ئىزاھات](#ئىزاھات) ۋە [ئىجازەتنامە](#ئىجازەتنامە) بۆلەكلىرىنى ئوقۇپ چىقىڭ.

## PiliBabel نېمە؟

PiliBabel — [PiliNara](https://github.com/Starfallan/PiliNara) ئاساسىدا قۇرۇلغان **مۇستەقىل ئۈچىنچى تەرەپ فوركى** بولۇپ، ئۇ PiliNara مىراسلىنىدىغان ھەممە نەرسىنى مىراسلىنىدۇ:

```
bilibili (رەسمىي ئاممىۋى API)
        ▲
   PiliPala / PiliPalaX        — ئەسلى قۇرۇلۇش
        ▲
   PiliPlus                    — ئاكتىپ فورك
        ▲
   PiliNara                    — PiliPlus نىڭ فوركى (شەخسىي ئۆزگەرتىشلەر)
        ▲
   PiliBabel  ← سىز بۇ يەردە   — PiliNara نىڭ فوركى
```

PiliBabel **PiliNara / PiliPlus نىڭ ھەممە ئىقتىدارىنى ساقلايدۇ** (ئاستى تەرەپتىكى [مىراسلىنىدىغان ئىقتىدار خاتىرىسى](#مىراسلىنىدىغان-ئىقتىدار-خاتىرىسى-pilinara--piliplus) نى كۆرۈڭ) ھەمدە يۇقىرى ئېقىن خېرىدارلىرىدا يوق **ئىككى باش ئىقتىدار قوشىدۇ**:

> **AI ئارايۈز ۋە مەزمۇن تەرجىمىسى** — پۈتۈن ئەپ (ئارايۈز يېزىقلىرى، سىن ماۋزۇلىرى، UP ئىسىملىرى، ئىنكاسلار، دىنامىكا، ئېقىم، ھەتتا بىۋاسىتە تارقىتىلدىغان دانماكۇلار) **سىز** تاللىغان تىلدا كۆرسىتىلىدۇ.

1.0 دىن باشلاپ بۇ **ئورنىتىلغان ھامان** ئىشلەيدۇ: تەرجىمە مودېلى **ئىچىگە كىرىشتۈرۈلگەن**. bilibili ئۆزىنىڭ تەرجىمە مودېل ئائىلىسىنى [Index-Translate](https://github.com/bilibili/Index-Translate) نامىدا ئوچۇق كودلىدى ھەمدە ئۇنى ھەقسىز ئاممىۋى ئېندپوئىنتتىن مۇلازىمەت قىلىدۇ. PiliBabel شۇنىڭغا باغلانغان ھالەتتە تارقىتىلىدۇ، شۇڭا تەرجىمە ئەپنى ئورناتقان مىنۇتتىلا ئىشلەيدۇ — تىزىملىتىش يوق، ئاچقۇچ يوق، ھەق يوق. ئۆز مودېلىڭىزنى ئىشلەتمەكچى بولسىڭىز، ئۆز API يولى ھېلىمۇ مەۋجۇت، بىر چېكىم يىراقلىقتا.

> **راستىنلا ماس قەدەمدە تۇرىدىغان تىڭشىغۇچ ئاۋازى** — Bluetooth ياكى سىملىق تىڭشىغۇچ بىلەن ئاۋاز ئەمدى كۆرۈنۈشتىن كەينىدە قالمايدۇ. رەسمىي ئەپ بۇنى توغرا ئىجرا قىلىدۇ؛ PiliNara ۋە PiliPlus بولسا ئورنىتىلغان پېتى بۇنى قىلالمايدۇ. PiliBabel ئەمدى mpv دىن ئالدى بىلەن **AudioTrack** نى تەلەپ قىلىدۇ، ئۇ چىقىرىش كېچىكىشىنى رەسمىي خېرىداردىكىگە ئوخشاش *ئۆلچەيدۇ*، پەقەت *مۆلچەرلەيدىغان* **OpenSL ES** ئەمەس.

## ئاساسلىق ئىقتىدارلار

- **ماس قەدەمدىكى تىڭشىغۇچ ئاۋازى.** قويغۇ ئەمدى سۈكۈتتىكى ھالەتتە mpv نىڭ **AudioTrack** ئارقا ئۇلىنىشىنى ئىشلىتىدۇ (`audiotrack,aaudio,opensles` تەرتىبى) **OpenSL ES** نىڭ ئورنىغا. AudioTrack *ئۆلچەنگەن* چىقىرىش كېچىكىشىنى دوكلات قىلىدۇ — ئۇ قويۇلغان بۆلەك سانى بىلەن ئۈسكۈنە كۆرسىتىش ۋاقىت بەلگىسىنى ئوقۇيدۇ — رەسمىي bilibili ئەپى ۋە Android نىڭ ئۆز `MediaSync` ى دەل مۇشۇ ئۇسۇل بىلەن سۈرەت بىلەن ئاۋازنى بىرلىكتە تۇتۇپ تۇرىدۇ. OpenSL ES ئۇنى پەقەت *مۆلچەرلەيدۇ*، شۇڭا Bluetooth تىڭشىغۇچتا ئاۋاز سائىتى سىيرىلىپ، سۈرەت بالدۇر كۆرسىتىلىپ قالاتتى. سىناق جەريانىدا كېچىكىش ئەمەلىيەتتە يوقالدى. تەرتىپىنى ھەر ۋاقىت تەڭشەكلەر → سىن → ئاۋاز چىقىرىش ئۈسكۈنىسى بۆلىمىدىن ئۆزگەرتەلەيسىز.

- **AI تەرجىمە، ھەممىلا يەردە.** يول باشلاش بەتكۈچلىرى، سىن كارتىلىرى، تەپسىلات بەتلىرى، ئىنكاسلار، دىنامىكا ۋە مېنىڭكى / يىغقانلىرىم / تارىخ / ئۇچۇرلار / ئىزدەش بەتلىرى — ئومۇمىي بىر ئۆتكۈزۈش **~1,650+ ئارايۈز جۈملىسى** نى قاپلايدۇ، شۇنداقلا ھەرىكەتچان مەزمۇننى (ماۋزۇلار، ئاپتور ئىسىملىرى، ھەرىكەت ساناقچىلىرى)مۇ ئۆز ئىچىگە ئالىدۇ.
- **ئىككى موتور، بىر ۋىكليۇچاتېل.** *كىرىشتۈرۈلگەن* (سۈكۈتتىكى) موتور bilibili نىڭ رەسمىي **Index-Translate-35B-A3B** ھەقسىز ئېندپوئىنتىنى ئىشلىتىدۇ — سەپلەيدىغان ھېچنېمە يوق. *ئۆز API* ئىلگىرىكى ھەرىكىتىنى ساقلايدۇ: ئۇنى ئۆز ئاساسىي URL / ئاچقۇچ / مودېلىڭىز بىلەن خالىغان OpenAI غا ماس `/chat/completions` ئېندپوئىنتىغا باغلاڭ. AI سىن-خۇلاسە ئىقتىدارى بىلەن AI تەرجىمە ئىقتىدارىنىڭ ئېندپوئىنتلىرى ۋە تەڭشەكلىرى يەنىلا **پۈتۈنلەي مۇستەقىل**، ئىككىلىسى بىر **«AI ئىقتىدارلىرى»** بېتىدە توپلانغان.
- **بىر تىل تىزىملىكى، ئىككى موتورغا ئورتاق.** نىشان تىللار تىزىملىكى موتورلار بويىچە ئايرىلمايدۇ — قايسى موتورنى تاللىسىڭىزمۇ ئوخشاشلا شۇ بىر تىزىملىك كۆرسىتىلىدۇ. ئۇ bilibili نىڭ رەسمىي مودېلىنىڭ **151 تىلى** نى ئۇ قاپلىمايدىغان **يەنە 6 تىل** بىلەن بىرلەشتۈرىدۇ: ئەنئەنىۋى خەنزۇچە، ئىخچام ۋە ئەنئەنىۋى ۋۇ تىلى، ئىچكىرى ۋە تەيۋەن خوكيەن تىلى، شۇنداقلا جۇاڭ تىلى. رايون ۋە يېزىق نۇسخىلىرى قوشۇلۇپ كەتمەي **ئايرىم تۈر** سۈپىتىدە ساقلىنىدۇ — ماراكەش / مىسىر / نەجد / لېۋانت ئەرەبچىلىرىنىڭ ھەربىرى ئۆز ئالدىغا تاللاش، كىرىل ۋە لاتىن يېزىقىدىكى سېرب، ئۆزبېك ۋە ئۇردۇ تىللىرىمۇ شۇنداق.
- **قاپلىنىش توغرىسىدا سەمىمىي.** رەسمىي تىزىملىك ئىچىدىكى تىللارنى bilibili مودېلى قاپلايدۇ. ئۇنىڭ سىرتىدىكى بىرنەچچە تىل — ئەنئەنىۋى خەنزۇچە، ئىخچام ۋە ئەنئەنىۋى ۋۇ تىلى، ئىچكىرى ۋە تەيۋەن خوكيەن تىلى ۋە جۇاڭ تىلى — تىزىملىكتە يەنىلا كۆرۈنىدۇ ھەمدە شۇنداقلىقى بەلگىلىنىدۇ، شۇ ئارقىلىق ياخشىراق نەتىجە ئۈچۈن ئۆز مودېلىڭىز كېرەك بولۇشى مۇمكىنلىكىنى بىر قاراپلا بىلىۋالايسىز.
- **بىر قېتىم تەرجىمە قىلىنسا، ئاندىن مۇقىملىشىدۇ.** ھەربىر مەنبە جۈملە **دەل بىر قېتىملا** تەرجىمە قىلىنىدۇ؛ نەتىجە يەرلىكتە ساقلىنىدۇ ھەمدە ئېكراننى قايتا ئاچقاندا **قايتا تەرجىمە قىلىنمايدۇ** — رەسمىي خېرىداردىكىگە ئوخشاش پىرىنسىپ بولۇپ، مۇقىم، ئالدىن پەرەز قىلغىلى بولىدىغان تەرجىمىلەر ئۈچۈندۇر.
- **ھەربىر ئىنكاس ئۈچۈن ئەسلى ⇄ تەرجىمە ۋىكليۇچاتېلى** (خەنزۇچە سۆز ئەمەس، كىچىك سىنبەلگە). `@تىلغا ئېلىشلار / [ئىپادىلەر] / #تېمىلار# / ئۇلانمىلار` توكېن سۈپىتىدە ساقلىنىدۇ ھەمدە **ئۇلانما ئۆز ئىچىگە ئالغان ئىنكاسلارمۇ تەرجىمە قىلىنىدۇ، ئۇلانما چېكىشكە بولىدىغان ھالەتتە ساقلىنىدۇ**.
- **دانماكۇ (弹幕) تەرجىمىسى** — قويغۇنىڭ ئوڭ ئۈستى كونترول قۇرىدىكى مۇستەقىل ۋىكليۇچاتېل، **سۈكۈتتىكى ھالەتتە ئۆچۈك** ھەمدە ئۆز مەتنىڭمۇ تەرجىمە قىلىنىدىغان جەزملەش ئارقىسىغا يوشۇرۇنغان. ئېچىلغاندىن كېيىن قويۇش ئورنىنىڭ ئالدىدىكى دانماكۇلار **تەخمىنەن 15 سېكۇنتلىق گۇرۇپپىلار بويىچە** ئالدىن تەرجىمە قىلىنىدۇ (ئوتتۇرىغا ئاتلاش باشتىن ئەمەس، توغرا بىر تەرەپ قىلىنىدۇ)، شۇڭا تەرجىمە ئادەتتە دانماكۇ ئېكرانغا كىرىپ بولغۇچە تەييار بولۇپ بولىدۇ.
- **ئويلىنىش ھالىتى ۋىكليۇچاتېلى** (`enable_thinking`) سۈپەت بىلەن سۈرئەت ئارىسىدىكى تاللاش ئۈچۈن، شۇنداقلا تەڭشەكلەردىكى **«تەرجىمىنى سىناش»** ۋە **غەملەكنى تازىلاش** توپچىلىرى.
- **تېز تىل ئالماشتۇرۇش**: مۇقىم غەملەككە قارىتىلغان چەكلىك بىۋاسىتەلىك بىلەن گۇرۇپپىلانغان ئىلتىماسلار؛ تىل ئالماشتۇرغاندا نۆۋەتتىكى ئېكران بىر قېتىم قايتا قۇرۇلىدۇ، شۇڭا تەرجىمە قىلىنمىغان تېكىستكە تىكىلىپ ئولتۇرۇپ قالمايسىز. AI تەرجىمىنى ئۆچۈرۈش پۈتۈن ئارايۈزنى ئەسلى تېكىستكە قايتۇرىدۇ ھەمدە ئازراقمۇ ئىلتىماس يوللىمايدۇ.
- **تۇنجى قوزغىتىلغاندا قارشى ئېلىش.** ئەپنى تۇنجى قېتىم ئاچقىنىڭىزدا ئىنگلىزچە سۆزلەشكۈ تەرجىمىنى ئېچىشنى تەۋسىيە قىلىدۇ. قوبۇل قىلىش تەرجىمىنى ئېچىپ، كىرىشتۈرۈلگەن مودېلنى تاللاپ، AI تەڭشەك بېتىنى ئاچىدۇ ھەمدە قايسى تىلنى خالايدىغانلىقىڭىزنى دەرھال سورايدۇ — يېڭى ئىشلەتكۈچى ئورنىتىشتىن تەرجىمە قىلىنغان ئەپكە ئىككى چېكىم بىلەنلا يېتىپ بارىدۇ.
- **پۈتۈن دۇنيادا ئىشلەيدىغان قويۇش.** PiliBabel سىزنى ئىچكىرى (Aliyun/Shenzhen) تۈگۈنىگە مىخلاپ قويماستىن، bilibili نىڭ جۇغراپىيىلىك يۆنىلىشلىك `playurl` ى ئاللىبۇرۇن ئوتتۇرىغا قويىدىغان چەتئەل گىرۋىكىنى (يەرشارى **Akamai**، `mirror*ov`، `cn-hk-eq-bcache`) تاللايدۇ — شۇنىڭ بىلەن ئىچكىرى جۇڭگو سىرتىدىكى ئىشلەتكۈچىلەر ئەمدى قېتىپ قالمايدۇ («ئاۋاز ئۆرۈلۈۋېرىدۇ، سىن قېتىپ قالىدۇ»). CDN نى تەڭشەكلەردىن قولدا مىخلىيالايسىز.
- **Material You ئۇسلۇبىدىكى «ئۇسلۇب ۋە رەڭ» بېتى.** يورۇق / قاراڭغۇ / سىستېمىغا ئەگىشىش **ئۈچ جانلىق ئالدىن كۆرۈش كارتىسىدىن** تاللىنىدۇ — ھەربىرى ھەقىقىي ئارايۈزنىڭ كىچىكلىتىلگەن كۆرۈنۈشىنى شۇ ھالەت قوللىنىدىغان دەل رەڭلەر بىلەن كۆرسىتىدۇ («سىستېمىغا ئەگىشىش» كارتىسى دىئاگونال بويىچە بۆلۈنگەن: ئۈستى يورۇق، ئاستى قاراڭغۇ). ئۇلارنىڭ ئاستىدا: **ھەرىكەتچان رەڭ** (ئۈسكۈنە قوللىسا سىستېما تام قەغىزىدىن ئېلىنىدۇ)، **يۇقىرى كونتراستلىق قاراڭغۇ** (ھەقىقىي قارا يۈزلەر، كېچىدە كۆزگە يېقىملىق) ۋە **ھەمىشە قاراڭغۇ قويغۇ**. رەڭ تەرىپى FlexScheme رەڭ دەستىسىنىڭ تولۇق يىغىنتۇقىنى ساقلايدۇ — **19 ئۇرۇق رەڭ** ۋە ھەربىر قاچا رەڭگىنىڭ ئۇرۇقتىن قانداق ھاسىل بولىدىغانلىقىنى بەلگىلەيدىغان، تاللانغان ئۇرۇقتىن مۇستەقىل بولغان ئايرىم **«رەڭ دەستىسى ئۇسلۇبى»**.
- **LXGW WenKai ئەپ بىلەن بىللە كېلىدۇ.** **LXGW WenKai (霞鹜文楷)** خەت نۇسخىسى **قىستۇرۇلغان ھەمدە سۈكۈتتىكى ھالەتكە تەڭشەلگەن** — ئىللىق، ئوقۇشقا ئىنتايىن قۇلاي خەنزۇچە خەت نۇسخىسى بولۇپ، ئورناتقان مىنۇتتىلا ئىلكىڭىزدە بولىدۇ، تاللاش تىزىمى ئىچىدىن ئىزدىمىسىڭىزمۇ بولىدۇ. ئۇ پۈتۈن ئارايۈزگە *ھەم* دانماكۇغا قوللىنىلىدۇ. يەنىلا سىستېما خەت نۇسخىسىغا قايتالاشقا، ئورنىتىلغان خالىغان سىستېما خەت نۇسخىسىنى تاللاشقا ياكى ئۆزىڭىزنىڭ `.ttf` / `.otf` / `.ttc` ھۆججىتىنى ئەكىرىشكە بولىدۇ؛ ئىلگىرى ئېنىق تاللاپ قويغان خەت نۇسخىڭىز يېڭىلاشتىن كېيىنمۇ ساقلىنىپ قالىدۇ. ئېغىرلىق ۋە چوڭلۇق بۇرۇنقىدەكلا تەڭشىلىدۇ.

## تورسىز ئاۋاز غەملەش ۋە يەرلىك قىسقۇچقا چۈشۈرۈش (PiliBabel غىلا خاس)

يۇقىرى ئېقىن PiliNara / PiliPlus تا يوق ئىككى ئىقتىدار — ھەر ئىككىلىسى مېدىيالىرىڭىزنى تورسىز ھالەتتە ھەقىقىي ئىلكىڭىزگە ئېلىشقا قارىتىلغان.

### ئاۋازنى غەملەش (پەقەت ئاۋازنىلا تورسىز غەملەش)

- **سىن ئەمەس، ئىزچىل.** *ئاۋازنى غەملەش* تۈرى سىن بېتى تىزىملىكىدە *سىننى غەملەش* نىڭ دەل ئاستىدا بولىدۇ، شۇنداقلا سىن ئاڭلاش بېتىنىڭ ئۈستى بالدىقىدا مەخسۇس ئاۋاز غەملەش توپچىسى بار.
- **سۈپەت دەرىجىسىنى تاللاڭ.** Hi-Res زىيانسىز، Dolby Atmos، 192K، 132K ياكى 64K — سىن سۈپىتى تاللىغۇچىسى ئىشلىتىدىغان ئوخشاش ئالدىن بېكىتىلگەن تىزىملىك.
- **ئەسلى قاچىلىغۇچ، قايتا كودلاش يوق.** ھۆججەت CDN بەرگەن پېتى يېزىلىدۇ: `m4a`، `mp3`، `flac`، `wav`، `aac` ياكى `ogg`.
- **ئۆز مودۇلى.** غەملەك بېتى *غەملەنگەن سىنلار* / *غەملەنگەن ئاۋازلار* دەپ بۆلۈنىدۇ ھەمدە ئالدىنقى قېتىم قايسى مودۇلدا بولغىنىڭىزنى ئەستە تۇتىدۇ.
- غەملەنگەن ئاۋاز تۈرىنى چەكسىڭىز ئاۋاز قويغۇسى دەرھال ئېچىلىدۇ؛ تۈرلەرنى بىر-بىرلەپ ياكى توپلىشىپ ئۆچۈرگىلى بولىدۇ.

### يەرلىك قىسقۇچقا چۈشۈرۈش

- **ئۆز تىزىملىك تۈرى.** *يەرلىك قىسقۇچقا چۈشۈرۈش* — سىن بېتى تىزىملىكىدىكى ئايرىم تۈر بولۇپ، *ئاۋازنى غەملەش* نىڭ دەل ئاستىدا — ئەپ ئىچىدە غەملەش بىلەن قىسقۇچقا ساقلاش ئىككى ئوخشىمىغان ھەرىكەت.
- **سىن چۈشۈرۈش ياكى ئاۋاز چۈشۈرۈش.** تۈر ئالدى بىلەن قايسىسىنى خالايدىغانلىقىڭىزنى سورايدۇ، ئاندىن سۈپەت دەرىجىسىنى سورايدۇ (سىن سۈپىتى / ئاۋاز سۈپىتى تاللىغۇچىسى).
- **قىسقۇچىڭىز، قائىدىلىرىڭىز.** سىستېما ھۆججەت باشقۇرغۇچىسى ئارقىلىق خالىغان قىسقۇچنى تاللاڭ (تەڭشەكلەر → *يەرلىك قىسقۇچقا چۈشۈرۈش*) ۋە خالىغان ۋاقىتتا ئۆزگەرتىڭ ياكى تازىلاڭ. تېخى تاللىمىغان بولسىڭىز، قىسقۇچ تاللىغۇچىسى شۇ جايدىلا ئېچىلىدۇ.
- **بىۋاسىتە قويغىلى بولىدىغان ھۆججەتلەر.** سىن بىرلا قوشۇلغان ئېقىم سۈپىتىدە ئېلىنىدۇ (`fnval=1`)، شۇڭا دىسكىغا چۈشىدىغىنى خالىغان قويغۇغا بەرگىلى بولىدىغان ئاددىي MP4 — بىرلەشتۈرۈشكە تېگىشلىك قوشۇمچە ئېقىملار يوق.
- **ئاۋاز ئەسلى فورماتىنى ساقلايدۇ** — قايتا كودلاش يوق، ئەپ ئىچىدىكى غەملەككە ئوپمۇ-ئوخشاش.
- ھۆججەتلەر سىن ماۋزۇسى بويىچە ئاتىلىدۇ ھەمدە بار بولغان چۈشۈرۈلمىنى ھەرگىز ئۈستىدىن يازمايدۇ.

## ئىككى تەرجىمە موتورى

| | كىرىشتۈرۈلگەن (سۈكۈتتىكى) | ئۆز API |
|---|---|---|
| مودېل | bilibili **Index-Translate-35B-A3B** | OpenAI غا ماس كېلىدىغان خالىغان مودېل |
| ئېندپوئىنت | `index-translate.bilibili.com/v1` | ئۆز ئاساسىي URL ىڭىز |
| API ئاچقۇچى | **كېرەك ئەمەس** | ئۆزىڭىزنىڭكى |
| ھەققى | ھەقسىز | مۇلازىم بەرگۈچىڭىز ئالىدىغان ھەق |
| ئىلتىماسلار | ھەر ئىلتىماسقا بىر جۈملە | گۇرۇپپىلانغان (ھەر ئىلتىماسقا ≤ 16) |
| قوشۇمچە تىللار | — | مودېلىڭىز بىلىدىغان خالىغان تىل |

**كىرىشتۈرۈلگەن موتور ئۈچۈن نېمە ئۈچۈن ھەر ئىلتىماسقا بىر جۈملە.** Index-Translate — تەرجىمىنىڭ *مۇتەخەسسىسى*، ئۇنىڭ ئاپتورلىرى ھۆججەتلەپ چىققان چاقىرىش ئەندىسى بولسا بىر تۈرلۈك قېلىپ («تۆۋەندىكى تېكىستنى X تىلىغا تەرجىمە قىل، پەقەت تەرجىمىنىلا چىقار»). شۇڭا PiliBabel بۇ موتوردا ئۆز API ئۈچۈن ئىشلىتىدىغان نومۇرلانغان تىزىملىك/JSON-ماترىتسا گۇرۇپپا سوئالىنىڭ ئورنىغا ھەر ئىلتىماسقا بىر جۈملىلا ئەۋەتىدۇ. ئېندپوئىنت ھەقسىز، شۇڭا گۇرۇپپىلاپ چىقىرىشقا دو تىكىشىڭنىڭ پايدىسى يوق — بۇ، بىرنەچچە ئارتۇق ئىلتىماسنى ئاز ساندىكى مەغلۇبىيەت يوللىرىغا تېگىشلەشتىن ئىبارەت ئاڭلىق تاللاش.

**0.3.x تىن يېڭىلاش.** ئۆز API تەڭشەكلىرىڭىز — ئاساسىي URL، ئاچقۇچ ۋە مودېل — **سىز سەپلىگەن پېتى قېلىۋېرىدۇ**. موتور تاللىشى پەقەت سۈكۈت بويىچە كىرىشتۈرۈلگەن مودېلغا ئۆتىدۇ، شۇڭا يېڭىلىغاندىن كېيىنكى تۇنجى قوزغىتىشتا bilibili نىڭ ھەقسىز مودېلىدا بولىسىز؛ *تەڭشەكلەر → AI → AI ئىقتىدارلىرى → تەرجىمە موتورى* بۆلىمىگە كىرىپ *ئۆز API* گە قايتىڭ، شۇ ھامان ئىلگىرىكى سەپلىمىڭىزگە قايتىسىز.

## AI ئارايۈز تەرجىمىسى قانداق ئىشلەيدۇ (تېخنىكىلىق)

ساقلانمىدا **i18n / ARB بايلىق قاتلىمى يوق** — ئارايۈز جۈملىلىرى قاتتىق كودلانغان خەنزۇچە. ھەربىر ۋىجېتنى قايتا يېزىشنىڭ ئورنىغا PiliBabel ئۈستىگە نېپىز بىر تەرجىمە قاتلىمى قوشىدۇ:

1. **ئومۇمىي ئىزدەش ئورالمىسى.** `lib/services/ui_translate/` ئالىي دەرىجىلىك `uiTx(String src)` فۇنكسىيىسىنى ئاشكارىلايدۇ. ئىلگىرى `Text('中文')` بولغان ۋىجېت تېكىستى `Text(uiTx('中文'))` بولىدۇ. سكرىپتلانغان **كودمود** بۇنى پۈتۈن قۇرۇلۇشقا قوللانغان (`tool/ui_translate_*.py`) — تەخمىنەن **223 ھۆججەت / ~1,650+ جۈملە** — ئۆز ئورنىغا ئىشلىتىشكە بولمايدىغان `const` ھالقىلىق سۆزىنى زۆرۈر جايلاردا ئاپتوماتىك ئېلىپ تاشلاپ (جۈملىدىن `const X<T>(...)` دەك گېنېرىكلار ۋە `const Positioned.fill(...)` دەك چېكىتلىك ئىسىملار، شۇنداقلا `static const` تىزىملىك/خەرىتە ئېلانلىرىنى `static final` غا ئايلاندۇرۇپ).
2. **`GetxService` يادروسى** (`ui_translate_service.dart`):
   - GetStorage ئاساسىدىكى مۇقىم **مەنبە → تەرجىمە** غەملەكى، شۇڭا ھەربىر جۈملە بىر قېتىم تەرجىمە قىلىنىپ مەڭگۈ قايتا ئىشلىتىلىدۇ؛
   - `tx()` ئالدى بىلەن `RxInt revision` نى ئوقۇيدۇ، ئاندىن قارار چىقىرىدۇ: ئۆچۈك بولسا → ئەسلىنى قايتۇرۇش؛ نىشان **ئىخچام خەنزۇچە (`zh-CN`)** بولسا API ئىلتىماسىسىزلا ئەسلىنى قايتۇرۇش (bilibili نىڭ مەنبە مەزمۇنىنىڭ مۇتلەق كۆپ قىسمى ئىخچام خەنزۇچە). باشقا بارلىق نىشانلار — ئەنئەنىۋى خەنزۇچە، كانتونچە، ۋۇ/شاڭخەيچە ۋە خوكيەن/مىننەننى ئۆز ئىچىگە ئالغان — سەپلەنگەن موتوردىن ئۆتىدۇ؛ پەقەت خەنزۇ تىللىرى ئائىلىسىگە تەۋە بولۇشلا تەرجىمىنى ئاتلىتىۋەتمەيدۇ. ئاندىن غەملەكتىن ياكى **نۆۋەتكە**؛
   - نۆۋەتتىكى جۈملىلەر **ئىشچىلار توپى** تەرىپىدىن **بۆلەك بويىچە تەدرىجىي قوللىنىش** بىلەن يوللىنىدۇ (قايتىپ كەلگەن ھەربىر بۆلەك `revision` نى ئۆستۈرىدۇ، شۇڭا تېكىست ئاستا-ئاستا يېڭىلىنىدۇ)، نەتىجىلەر **ساقلىنىدۇ** (ئاستىلىتىلىپ). گۇرۇپپا چوڭلۇقى ۋە بىۋاسىتەلىك موتورغا باغلىق: كىرىشتۈرۈلگەن مودېلدا **ھەر ئىلتىماسقا 1**، ئۆز API دا **ئۇچۇۋاتقىنى ≤ 10 بولغان ئەھۋالدا ≤ 16**.
3. **موتور ھەل قىلىش.** `TranslateProvider` (`builtin` / `custom`) ترانسپورتنىڭ قايسى URL، ئاچقۇچ ۋە مودېلنى ئىشلىتىدىغانلىقىنى بەلگىلەيدۇ؛ ئىككى موتور باشقا جەھەتتە بىر كود يولى ۋە بىر تىل تىزىملىكىنى ئورتاق ئىشلىتىدۇ، شۇڭا موتور ئالماشتۇرۇش بىرلا تەڭشەك بولۇپ، ئەزەلدىن ئوخشىمىغان ئىقتىدار توپلىمى ئەمەس.
4. **ترانسپورت** AI سىن خۇلاسىسى بىلەن ئوخشاش دەلىللەنگەن **ئېقىملىق** ئۆزىكىنى قايتا ئىشلىتىدۇ — `AiChatService.streamChat` → `{base}/chat/completions`، `stream: true` بىلەن (پەقەت ئېقىملىقنى قوللايدىغان دەرۋازىلارغىمۇ ماس) — تەرجىمە ئۆز **ئايرىم** `apiUrl` / `apiKey` / `model` قىممەتلىرى ۋە `enable_thinking` بەلگىسىنى ئىشلىتەلەيدىغان قىلىپ كېڭەيتىلگەن. بۇ ئۆزگىرىش **كەينىگە ماس**، شۇڭا سىن خۇلاسىسى ئۆزگەرمەي ئىشلەۋېرىدۇ.
5. **قىستۇرۇلغان جۈملىلەر** `uiTxP(template, args)` ئىشلىتىدۇ: `{0}`/`{1}` تولدۇرغۇچلىرى بار پۈتۈن بىر جۈملە بىر مۇقىم ئاچقۇچ سۈپىتىدە تەرجىمە قىلىنىدۇ (سوئال مودېلدىن تولدۇرغۇچلارنى ساقلاشنى تەلەپ قىلىدۇ)، ئاندىن قىممەتلەر ئورنىغا قايتا قويۇلىدۇ — شۇڭا `"共 {0} 条"` شەكلىدىكى جۈملىلەر ھەرىكەتچان قىسىملىرى بۇزۇلماي تەرجىمە قىلىنىدۇ.
6. **تىل جەدۋىلى** (`app_language.dart`): ھەربىر `AppLanguage` كۆرسىتىش ئاتالغۇسىنى، يېزىق/رايون ئەنئەنىلىرىنى كودلايدىغان `toModel` سوئال جۈملىسىنى ۋە bilibili نىڭ رەسمىي تىزىملىكىنىڭ ئۇنى قاپلىغان-قاپلىمىغانلىقىنى بىلدۈرىدىغان بەلگىنى ئېسىپ يۈرىدۇ. يېزىق قائىدىلىرى (ئىخچام بىلەن ئەنئەنىۋى، شۇنداقلا دىئالېكت بىردەكلىكى يوليورۇقلىرى) مودېلغا پەقەت سوئال ئارقىلىقلا يېتىپ بارىدۇ، خېرىدار تەرەپتىكى مۇقەررەر نورماللاشتۇرۇش ئۆتى كېيىن ئېزىپ قالغان ھەرپ-بەلگىلەرنى تۈزىتىدۇ.
7. **ئىنكاسلار** `uiTxComment(text, id)` دىن ئۆتىدۇ، `@ / [ئىپادە] / #تېما# / ئۇلانما` بىردەك پۈتۈك توكېن سۈپىتىدە ساقلىنىدۇ؛ ئۇلانما ئېلىپ يۈرىدىغان مول تېكىست بۆلەكلىرى ئۇلانما تونۇغۇچ ساقلانغان ھالەتتە تەرجىمە قىلىنىدۇ، ھەربىر ئىنكاسنىڭ id توپلامى ئەسلى ⇄ تەرجىمە ۋىكليۇچاتېلىنى باشقۇرىدۇ.
8. **دانماكۇ** (`danmaku/view.dart`): ۋىكليۇچاتېلى ئوچۇق بولغاندا، ئورۇن تىڭشىغۇچىسى `[قويۇش ئورنى، قويۇش ئورنى + 15 سېكۇنت]` ئارىلىقىنى سېكۇنت-سېكۇنتلاپ ئايلىنىپ چىقىپ، ھەربىر دانماكۇنىڭ مەزمۇنىدا `uiTx()` نى ئالدىن ئىجرا قىلىدۇ، شۇڭا تۈرلەر ئېكرانغا يېتىپ كېلىشتىن بۇرۇنلا تەرجىمە قىلىنىپ بولىدۇ؛ ئېچىلغاندا كانۋاس تازىلىنىپ قايتا سىزىلىدۇ.
9. **ساقلاش ئاچقۇچلىرى**: `uiTranslate{Enabled,Provider,Lang,Model,ApiUrl,ApiKey,Thinking,Cache,Onboarded}`. **تەڭشەك ئارايۈزى**: بىرىنچى دەرىجىلىك يالغۇز بىر «AI ئىقتىدارلىرى» بېتى (`lib/pages/setting/ui_translate/`) بولۇپ، ئىچىدە AI سىن خۇلاسىسى ۋە AI تەرجىمە ئۈچۈن مۇستەقىل بۆلەكلەر بار.

**يەرشارى CDN (`VideoUtils.getCdnUrl`).** ئېقىم URL لىرى ئىمزالانغان بولىدۇ، URL نىڭ خاس بۆلىكىنى قايتا يېزىش ئۇنى 403 بىلەن رەت قىلدۇرىدۇ — شۇڭا قويۇش جەريانى ئەزەلدىن خاس ناملارنى قايتا يازمايدۇ. PiliBabel بولسا bilibili نىڭ خېرىدار IP سىغا بەرگەن جۇغراپىيىلىك يۆنىلىشلىك URL نى قايتۇرىدۇ، نامزاتلار تىزىملىكىدە چەتئەل گىرۋىكى (`*.akamaized.net`، `mirror(cos|ali|hw)ov`، `cn-hk-eq-bcache`) بولسىلا شۇنىڭغا ئالدىنقى ئورۇن بېرىلىدۇ. خاس نام ئالماشتۇرۇش بىخەتەر بولىدىغان چۈشۈرۈشلەردە يەرشارى Akamai گىرۋىكىگە قوشۇمچە ئالدىنقى ئورۇن بېرىلىدۇ ھەمدە لىنىيە توختىغان ياكى داۋاملاشتۇرۇشنى رەت قىلغاندا كېيىنكى ئىمزالانغان نامزاتقا ئالماشتۇرۇلىدۇ. `/v/resource` خام P2P ئۇلانمىلىرى 404 دىن ساقلىنىش ئۈچۈن يەنىلا ئۆز ئالدىغا رېلەيغا قايتىدۇ.

**لايىھە تەڭپۇڭلۇقلىرى / مەلۇم چەكلىمىلەر.** جۈملىلەر بايلىققا ئايرىلماي، ئۆز ئورنىدا ئورالغانلىقتىن، `Text` بولمىغان بىرنەچچە جۈملە پارامېتىرى ۋە بەزى مول تېكىست بۆلەكلىرى ھېلىھەم تەدرىجىي تولدۇرۇلماقتا. **لوگىكا ئاچقۇچى** سۈپىتىدە خىزمەت قىلىدىغان جۈملىلەر (`==` بىلەن سېلىشتۇرۇلىدىغان، `简介` دەك بەتكۈچ ئىسىملىرى سۈپىتىدە ئىشلىتىلىدىغان ياكى switch لاردا ئىشلىتىلىدىغان enum بەلگىلىرى) ھەرىكەتنى بۇزماسلىق ئۈچۈن قەستەن **ئومۇميۈزلۈك ئورالمايدۇ**. دانماكۇ تەرجىمىسى سىيرىلىۋاتقان كانۋاستا «كۈچىنىڭ بارىچە» ئىجرا قىلىنىدۇ — ئىنتايىن زىچ دانماكۇدا تەرجىمە يېتىپ كېلىشتىن ئىلگىرى قىسقا ۋاقىت ئەسلى تېكىستنى كۆرۈپ قېلىشىڭىز مۇمكىن. تەرجىمىگە تور كېرەك؛ تور بولمىسا، خەنزۇچە بولمىغان نىشانلار پەقەتلا كۈچكە ئىگە بولمايدۇ. كىرىشتۈرۈلگەن ئېندپوئىنت — bilibili يۈرگۈزىدىغان ھەقسىز ئاممىۋى مۇلازىمەت — ئۇ بىر كۈنى چەكلىنىپ قالسا ياكى ئىشلىمەي قالسا، ئەپ سىزگە شۇنى ئۇقتۇرىدۇ ھەمدە ئۆز API گە ئۆتەلەيسىز.

**خەت نۇسخا سىستېمىسى** — مەزمۇن-hash ئارقىلىق تەكرارلىنىشنى چەكلەيدىغان بىرلەشمە ئەكىرىش كۆلى، دانماكۇ خەت نۇسخىلىرى شۇ كۆلگە قوشۇلغان، ttc قوللايدىغان `loadFontFromList` ۋە ساپ-ASCII hash ئائىلە ئاتلىرى.

**قويۇش، كىچىك كۆزنەك ۋە سۈپەت** — ئەپ ئىچىدىكى كىچىك كۆزنەك (سۆرەش، چوڭلۇقنى ئۆزگەرتىش، SponsorBlock نى ئاتلىتىۋېتىش، ئۆزلۈكىدىن سىستېما PIP، بىۋاسىتە تارقىتىشتا ئۆزىنى قۇتقۇزۇش بالدىقى)، قوشۇمچە ئاۋازنى تەڭ قويۇش، ئەپ ئىچىدىكى ئاۋاز 200% كىچە، سىن CDN دائىرىسىنى ئۆزگەرتىش ۋە كېچىكىش سىنىقى بىلەن رايون تۈگۈنى تاللاش، يېرىم/تولۇق ئېكرانغا ئايرىم سۈكۈتتىكى سۈپەت، ئۈستىگە سىيرىپ سۈرئەت قۇلۇپلاش، پلانشېت (پاد) كۇنۇپكا تاختىسىدا كونترول قىلىش، بىۋاسىتە تارقىتىشتىكى SuperChat ۋاقىت بەلگىلىرى، مەستانە يېقىنلىقى ئۈچۈن جانلىق يۈرەك سوقۇشى.

**فىلىم خېتى، AI ۋە تورسىز ھالەت** — ئىككىنچى فىلىم خېتىگە ئايرىم بېزەك بېرىلىدىغان قوش تىللىق فىلىم خېتى، AI فىلىم خېتى تەھلىلى (ئۆز OpenAI غا ماس ئېندپوئىنتى، ۋاقىت بەلگىسىگە ئاتلاش، قېلىپلار، ساقلانغان سۆھبەتلەر، فىلىم خېتى بولمىغاندا يۇمشاق زاپاس لايىھە)، WEBVTT/SRT چىقىرىش، قىسقۇچ باشقۇرۇش ۋە مېتا سانلىق مەلۇمات ساقلاش بىلەن تورسىز غەملەكنىڭ قوش كۆرۈنۈشى، چۈشۈرۈلمىلەرنى ئاممىۋى Download قىسقۇچىغا چىقىرىش (Android).

**دانماكۇ ۋە پەچەتلەش** — كۈچەيتىلگەن بىرلەشتۈرۈلگەن دانماكۇ كۆلىمى ([Pakku.js](https://github.com/xmcp/pakku.js) ئۇسلۇبىدا)، ئەكىرىش/چىقىرىش بىلەن تىزىملىككە ئاساسلانغان كۆرۈنۈشلۈك regex پەچىتى، SponsorBlock بۆلەككە سەكرەشنى ئاتلىتىۋېتىش، گاۋس يادرولۇق يۇقىرى ئېنېرگىيىلىك ئىلگىرىلەش بالدىقى.

**تەۋسىيە / دىنامىكا / ئىنكاس سۈزگۈچلىرى** — ماۋزۇ/UP/قانال ئاچقۇچ سۆزلىرى، ئۇزۇنلۇق، كۆرۈلۈش سانى، ياقتۇرۇش نىسبىتى، ئەگىشىلگەن UP كەچۈرۈمى، ئىجازەتسىز/پەقەت ھەقلىقنى سۈزۈش، ئورتاق ئاق تىزىملىك، سودا/ئىجازەتسىز دىنامىكا، UP نىڭ ئۆز ئىنكاسى ۋە مۇقۇم ئىنكاس كەچۈرۈملىرى، App+Web بىرلەشمە ئېقىم ھالىتى.

**دىنامىكا، ئىزدەش ۋە ئىشلەتكۈچى ئۇچۇرى** — UP لارغا شەخسىي خاتىرە، 13 ئىسىم ئورنىدا تەخەللۇسنى خاتىرىگە ئالماشتۇرۇش، ئىچكىرىلەنگەن ئىنكاسلارنىڭ مۇستەقىل تەرتىپلىنىشى، يەرلىك ئاچقۇچ سۆز ئىزدەش سۈزگۈچى، b23.tv قىسقا ئۇلانمىسىغا ئاتلاش، پەقەت ھەقلىق بەلگىسى، تەۋسىيە سەۋەبىنى يوشۇرۇش ۋىكليۇچاتېلى، تەڭگە XP كۆرسىتىش.

**بىۋاسىتە تارقىتىش ياخشىلاشلىرى** — مەستانە مېدىلىنى تاقاش تاختىسى، HLS نى ئالدىن كۆرىدىغان DLNA تارقىتىش، SuperChat ۋاقتىنى كۆرسىتىش، ئۆزىنى قۇتقۇزۇش ئۈچۈن كىچىك كۆزنەكنىڭ ئاستى كونترول بالدىقى.

## ئىزاھات

PiliBabel — قىزىقىشتىن باشلانغان شەخسىي قۇرۇلۇش بولۇپ، **پەقەت ئۆگىنىش ۋە سىناش ئۈچۈن** تەمىنلىنىدۇ؛ چۈشۈرگەندىن كېيىن **24 سائەت ئىچىدە** ئۆچۈرۈۋېتىڭ.

- PiliBabel **رەسمىي ئەمەس ئۈچىنچى تەرەپ** خېرىدارى بولۇپ، **bilibili بىلەن مۇناسىۋەتسىز، ئۇنىڭ قوللىشىغا ئېرىشمىگەن ۋە ئىقتىسادىي قوللاشقا ئېرىشمىگەن**.
- بارلىق API رەسمىي ئاممىۋى ئېندپوئىنتلاردىن يىغىلغان؛ **يېشىلگەن، ئارتۇق ھوقۇقلۇق ياكى ھەق توسۇقىنى ئايلىنىپ ئۆتىدىغان ھېچقانداق مەزمۇن تەمىنلەنمەيدۇ**.
- **AI تەرجىمە ئۈچىنچى تەرەپ مودېل ئېندپوئىنتىدا ئىشلەيدۇ.** سۈكۈتتىكى ھالەتتە ئۇ bilibili نىڭ ئۆزىنىڭ ھەقسىز ئاممىۋى Index-Translate مۇلازىمىتى؛ ئۆز API گە ئالماشسىڭىز، ئۇ سىز سەپلىگەن ئېندپوئىنت بولىدۇ. تەرجىمە سۈپىتى ۋە قائىدىگە ئۇيغۇنلۇقى ئىشلەتكۈچى بىلەن تاللانغان مودېل مۇلازىم بەرگۈچىنىڭ مەسئۇلىيىتىدە؛ بۇ قۇرۇلۇش **مودېلمۇ، API ئاچقۇچىمۇ** تۇتمايدۇ.
- نەشر ھوقۇقى ۋە bilibili نىڭ مۇلازىمەت شەرتلىرىنى ھۆرمەتلەڭ. مەسئۇلىيەت بىلەن ئىشلىتىڭ.

ئەسلى ۋە يۇقىرى ئېقىن ئاپتورلىرىنىڭ ئوچۇق كودقا بولغان ساداقىتىگە ھۆرمەت بىلەن:
