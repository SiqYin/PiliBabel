# 關於第三方網站未經許可侵權分發PiliBabel安裝包个聲明

PiliBabel是開源、免費、嘸廣告个第三方Bilibili客戶端，代碼託管在上GitHub，以GPLv3協議發佈，並基於上游PiliNara / PiliPala繼續開發。專案嘸没商業實體，也嘸没任何付費版本。

本項目唯一个官方發佈渠道是GitHub Releases（github.com/SiqYin/PiliBabel/releases）。我伲從來朆授權任何網站、應用商店、公眾號或者網盤分發本軟件，也從來朆望任何第三方提供安裝包。

近期我伲發現，西西软件园（cr173.com）、嗨客手机站（hackhome.com）、游吧乐下载（y8l.com）、289手游网（289.com）、乐乐游戏（6ll.com）等國内網絡平臺，在未經我伲許可个情况下，以「PiliBabel」「皮利宝贝」等名義分發本項目个v3.8.6安裝包。經取證比對，其檔案直接扒取自官方發佈渠道，而非箇星驛點自行獲得个合法副本；我伲搭上述驛點嘸没任何接觸或授權關係。箇點頁面既未隨附 GPLv3 許可證文本，也朆提供對應源碼个獲取方式，弗滿足本項目授權再分發个前提條件；部分頁面更使用「官方下载」「官方正版」「原始安装包」等表述冒稱官方或原始來源。上述未經許可个分發行為，已構成對本專案个侵權。

我伲要求上述網站立即落架侵權安裝包及相應宕落頁面；擔「官方下载」「官方正版」「原始安装包」等錯誤描述刪除脫，冒稱官方或原始來源停止脫；如欲繼續提供本軟件，須遵守GPLv3个全部條款，注明軟件真實來源，且弗得使用任何「官方」類表述。

我伲提醒每位尊敬个用戶：請在許GitHub官方渠道宕落 PiliBabel。從非官方渠道獲取个安裝包，我伲無法為其完整性、安全性搭後續更新負責；官方Release頁面全提供 SHA-256 校驗值，宕落後可自行核對。對於任何要求付費、關注公眾號、加群或者安裝「下载器」再好獲取个情况，請立即終止宕落；如已造成經濟損失，建議爾儂報警求助。

# Statement on Unauthorized Infringing Distribution of PiliBabel Installers by Third-Party Websites

PiliBabel is an open-source, free, ad-free third-party Bilibili client. The code is hosted on GitHub, released under the GPLv3 licence, and continues development from the upstream PiliNara / PiliPala project. There is no commercial entity behind it and no paid edition.

The only official release channel for this project is GitHub Releases (github.com/SiqYin/PiliBabel/releases). We have never authorised any website, app store, public account or cloud drive to distribute this software, and we have never supplied an installer to any third party.

We have recently discovered that online platforms in China, including 西西软件园 (cr173.com), 嗨客手机站 (hackhome.com), 游吧乐下载 (y8l.com), 289手游网 (289.com) and 乐乐游戏 (6ll.com), are distributing this project's v3.8.6 installers without our permission, under names such as "PiliBabel" and "皮利宝贝". Forensic comparison shows that the files were taken directly from the official release channel, not lawfully obtained by these sites; we have had no contact with, and have granted no authorisation to, the above sites. These pages include neither the GPLv3 licence text nor any means of obtaining the corresponding source code, and therefore fail the conditions under which redistribution of this project is permitted; some of them go further, using descriptions such as "official download", "official genuine version" and "the original installer" to falsely present themselves as an official or original source. Such unauthorised distribution constitutes an infringement of this project's rights.

We demand that the above websites immediately take down the infringing installers and the corresponding download pages; delete the false descriptions such as "official download", "official genuine version" and "the original installer", and stop presenting themselves as an official or original source; and should they wish to continue offering this software, they must fully comply with all terms of GPLv3, state the true origin of the software, and refrain from using the word "official" in any form.

We remind every valued user: please download PiliBabel from the official GitHub channel. We cannot stand behind the integrity, safety or continued updates of installers obtained from unofficial channels; the official Release pages all provide a SHA-256 digest, which you can verify after downloading. Whenever obtaining the installer requires payment, following a public account, joining a group, or installing a "downloader", stop the download immediately; if you have suffered any financial loss, we advise you to report it to the police.

For PiliBabel, versions, updates and installer packages take SiqYin's releases on GitHub as the sole standard.
